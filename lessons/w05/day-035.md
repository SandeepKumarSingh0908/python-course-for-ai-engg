## Quick Reference: NumPy (Days 29-31)

### Array creation

```python
import numpy as np

np.array([1, 2, 3])             # from list
np.zeros((3, 4))                # 3x4 of zeros
np.ones((2, 3))                 # 2x3 of ones
np.arange(0, 10, 2)             # [0, 2, 4, 6, 8]
np.linspace(0, 1, 5)            # 5 points from 0 to 1
np.eye(3)                       # 3x3 identity
np.full((2, 2), 7)              # 2x2 filled with 7
```

### Key attributes

```python
arr.shape    # dimensions as a tuple
arr.ndim     # number of dimensions
arr.size     # total number of elements
arr.dtype    # data type
arr.nbytes   # memory usage in bytes
```

### Indexing and selection

```python
arr[0, 1]                       # single element
arr[:, 0]                       # entire column
arr[arr > 5]                    # boolean mask
arr[[0, 2, 4]]                  # fancy indexing
np.where(arr > 0, arr, 0)      # conditional replacement
```

### Linear algebra

```python
A @ B                           # matrix multiplication
np.linalg.solve(A, b)          # solve Ax = b
np.linalg.inv(A)               # inverse
np.linalg.eig(A)               # eigenvalues + eigenvectors
np.linalg.svd(A)               # singular value decomposition
np.linalg.norm(v)              # L2 norm
```

### Statistics and random

```python
np.mean(arr, axis=0)           # column means
np.std(arr, axis=1)            # row standard deviations
np.argmax(arr)                 # index of max value
np.percentile(arr, 75)         # 75th percentile

np.random.seed(42)             # reproducibility
np.random.randn(3, 3)          # standard normal
np.random.normal(0, 1, (3, 3)) # parameterised normal
np.random.choice(arr, 5)       # random selection
```

## Quick Reference: Pandas (Days 32-34)

### Creation and inspection

```python
import pandas as pd

pd.Series([1, 2, 3])                    # 1-D labelled array
pd.DataFrame({"a": [1, 2], "b": [3, 4]})  # from dict
pd.read_csv("file.csv")                 # from CSV

df.shape       # (rows, cols)
df.dtypes      # column types
df.info()      # full summary
df.describe()  # statistics
df.head()      # first 5 rows
```

### Indexing

```python
df["col"]                # single column (Series)
df[["col1", "col2"]]     # multiple columns (DataFrame)
df.loc["label", "col"]   # label-based (inclusive)
df.iloc[0, 1]            # position-based (exclusive end)
df[df["col"] > 5]        # boolean filter
df.query("col > 5")      # query syntax
```

### Data cleaning

```python
df.isna().sum()                    # count missing per column
df.dropna(subset=["col"])          # drop rows missing in col
df.fillna(value)                   # fill missing
df["col"].interpolate()            # interpolate gaps

pd.to_numeric(s, errors="coerce") # safe numeric conversion
pd.to_datetime(s, errors="coerce")# safe date parsing
df["col"].astype("float32")       # explicit cast

df.duplicated().sum()              # count duplicates
df.drop_duplicates()               # remove duplicates

df["col"].str.strip()              # whitespace
df["col"].str.lower()              # case
df["col"].str.replace(r"\d+", "", regex=True)  # regex replace
```

### GroupBy, Merge, Pivot

```python
df.groupby("col").agg({"val": ["mean", "sum"]})  # grouped stats
df.groupby("col")["val"].transform("mean")         # broadcast back

pd.merge(df1, df2, on="key", how="left")   # SQL-style join
pd.concat([df1, df2], axis=0)               # stack rows

df.pivot_table(values="val", index="row", columns="col", aggfunc="sum")
df.melt(id_vars=["id"], value_vars=["a", "b"])   # wide to long
```
