## Section 1: Pandas Series

A Series is a one-dimensional labeled array. Think of it as a single column of a spreadsheet.

```python
import pandas as pd
import numpy as np

# From a list
scores = pd.Series([85, 92, 78, 90, 88])
print(scores)
# 0    85
# 1    92
# 2    78
# 3    90
# 4    88
# dtype: int64

# With a custom index
scores = pd.Series([85, 92, 78, 90, 88],
                    index=["Alice", "Bob", "Carol", "Dave", "Eve"])
print(scores["Bob"])      # 92
print(scores[1])           # 92 (positional still works)

# From a dictionary
temps = pd.Series({"NYC": 32, "LA": 72, "Chicago": 28, "Miami": 80})
print(temps)
```

### Series operations

```python
# Vectorized operations (just like NumPy)
celsius = (temps - 32) * 5 / 9
print(celsius.round(1))

# Boolean filtering
warm = temps[temps > 50]
print(warm)
# LA       72
# Miami    80

# Useful attributes and methods
print(scores.values)    # underlying NumPy array
print(scores.index)     # Index object
print(scores.dtype)     # int64
print(scores.name)      # None (can be set)
```

## Section 2: DataFrames -- Creation

A DataFrame is a 2-D labeled data structure -- like a spreadsheet, SQL table, or dictionary of Series.

### From a dictionary of lists

```python
data = {
    "name": ["Alice", "Bob", "Carol", "Dave", "Eve"],
    "age": [28, 35, 42, 31, 27],
    "score": [85.5, 92.0, 78.3, 90.1, 88.7],
    "passed": [True, True, False, True, True],
}

df = pd.DataFrame(data)
print(df)
#     name  age  score  passed
# 0  Alice   28   85.5    True
# 1    Bob   35   92.0    True
# 2  Carol   42   78.3   False
# 3   Dave   31   90.1    True
# 4    Eve   27   88.7    True
```

### From a NumPy array

```python
np.random.seed(42)
arr = np.random.randn(5, 3)
df_np = pd.DataFrame(arr, columns=["feature_1", "feature_2", "feature_3"])
print(df_np.round(3))
```

### From a list of dictionaries (common with JSON APIs)

```python
records = [
    {"model": "gpt-4", "params_b": 1800, "open_source": False},
    {"model": "llama-3", "params_b": 70, "open_source": True},
    {"model": "claude-3", "params_b": None, "open_source": False},
]
df_models = pd.DataFrame(records)
print(df_models)
```

## Section 4: Indexing -- loc, iloc, and []

This is the most important section. Mastering these three access patterns prevents hours of debugging.

### [] operator -- column selection and row slicing

```python
# Single column (returns a Series)
print(df["name"])

# Multiple columns (returns a DataFrame)
print(df[["name", "score"]])

# Row slicing by position (less common, but works)
print(df[1:3])   # rows at position 1 and 2
```

### loc -- label-based indexing

`loc` uses labels (index values and column names). Both endpoints are inclusive.

```python
# Set a meaningful index
df_indexed = df.set_index("name")

# Single value
print(df_indexed.loc["Bob", "score"])   # 92.0

# Single row (returns Series)
print(df_indexed.loc["Carol"])

# Multiple rows and columns
print(df_indexed.loc[["Alice", "Dave"], ["age", "score"]])

# Slicing with labels (INCLUSIVE on both ends!)
print(df_indexed.loc["Bob":"Dave", "age":"score"])
```

### iloc -- integer position-based indexing

`iloc` uses integer positions. Works like Python slicing (end is exclusive).

```python
# Single element
print(df.iloc[0, 1])    # 28 (row 0, column 1)

# Single row
print(df.iloc[0])

# Row and column ranges
print(df.iloc[1:4, 0:2])   # rows 1-3, columns 0-1

# Specific rows and columns by position
print(df.iloc[[0, 2, 4], [0, 2]])  # rows 0,2,4 and columns 0,2
```

### Boolean indexing

```python
# Filter rows where score > 85
high_scorers = df[df["score"] > 85]
print(high_scorers)

# Multiple conditions (use & for AND, | for OR, ~ for NOT)
filtered = df[(df["score"] > 80) & (df["age"] < 35)]
print(filtered)

# Using .query() -- a cleaner syntax for complex filters
result = df.query("score > 80 and age < 35")
print(result)
```

### Common gotcha: chained indexing

```python
# BAD -- may not work as expected (SettingWithCopyWarning)
# df[df["score"] > 85]["passed"] = False

# GOOD -- use loc for assignment
df.loc[df["score"] > 85, "passed"] = True
```

## Section 6: Worked Example -- Exploring a Model Evaluation Dataset

```python
import pandas as pd
import numpy as np
from io import StringIO

# Simulated model evaluation results
csv_data = """model,dataset,accuracy,f1_score,latency_ms,params_millions
bert-base,imdb,0.89,0.88,45.2,110
bert-large,imdb,0.92,0.91,120.5,340
distilbert,imdb,0.87,0.86,22.1,66
roberta,imdb,0.93,0.92,48.7,125
bert-base,sst2,0.91,0.90,44.8,110
bert-large,sst2,0.94,0.93,118.2,340
distilbert,sst2,0.88,0.87,21.5,66
roberta,sst2,0.95,0.94,47.3,125
"""

df = pd.read_csv(StringIO(csv_data))

# Step 1: Inspect
print(f"Shape: {df.shape}")
print(f"\nDtypes:\n{df.dtypes}")
print(f"\nFirst few rows:\n{df.head()}")

# Step 2: Which model has the highest average accuracy?
avg_accuracy = df.groupby("model")["accuracy"].mean()
print(f"\nAverage accuracy by model:\n{avg_accuracy.sort_values(ascending=False)}")

# Step 3: Find the most efficient model (best accuracy per million parameters)
df["efficiency"] = df["accuracy"] / df["params_millions"]
best = df.loc[df["efficiency"].idxmax()]
print(f"\nMost efficient: {best['model']} on {best['dataset']}")

# Step 4: Filter to fast models (latency < 50ms) with accuracy > 0.90
fast_accurate = df.query("latency_ms < 50 and accuracy > 0.90")
print(f"\nFast & accurate models:\n{fast_accurate[['model', 'dataset', 'accuracy', 'latency_ms']]}")
```

## Common Mistakes

- **Confusing `loc` and `iloc`.** `loc` is label-based (inclusive endpoints). `iloc` is position-based (exclusive end). Mixing them up causes off-by-one errors or KeyErrors.
- **Using chained indexing for assignment.** `df["col1"]["col2"] = value` triggers SettingWithCopyWarning and may silently fail. Always use `df.loc[row, col] = value`.
- **Forgetting `inplace=True` or reassignment.** Methods like `set_index`, `drop`, and `rename` return new DataFrames by default. Either pass `inplace=True` or reassign: `df = df.set_index("name")`.
- **Reading a CSV without checking dtypes.** Pandas may read numeric IDs as int64, dates as strings, or booleans as objects. Always run `df.dtypes` after loading.
- **Accidentally modifying the original DataFrame.** Many operations return views. Use `.copy()` when you need an independent DataFrame.
