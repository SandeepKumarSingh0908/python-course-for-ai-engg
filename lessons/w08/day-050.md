Whether you are building a chatbot, a summarization pipeline, or an autonomous agent, the interface is always the same: send a structured request to an API, receive a response, and handle errors gracefully. ## Section 2: Chat Completions

### OpenAI Chat Completions

```python
from openai import OpenAI

client = OpenAI()

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "You are a helpful Python tutor."},
        {"role": "user", "content": "Explain list comprehensions in one paragraph."},
    ],
    temperature=0.7,
    max_tokens=256,
)

# Extract the reply
reply = response.choices[0].message.content
print(reply)

# Inspect token usage
print(f"Prompt tokens:     {response.usage.prompt_tokens}")
print(f"Completion tokens: {response.usage.completion_tokens}")
print(f"Total tokens:      {response.usage.total_tokens}")
```

### Anthropic Messages API

```python
from anthropic import Anthropic

client = Anthropic()

message = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=256,
    system="You are a helpful Python tutor.",
    messages=[
        {"role": "user", "content": "Explain list comprehensions in one paragraph."},
    ],
    temperature=0.7,
)

reply = message.content[0].text
print(reply)

# Token usage
print(f"Input tokens:  {message.usage.input_tokens}")
print(f"Output tokens: {message.usage.output_tokens}")
```

**Key differences:**
| Feature | OpenAI | Anthropic |
|---|---|---|
| System prompt | Message with `role: "system"` | Top-level `system` parameter |
| Response text | `response.choices[0].message.content` | `message.content[0].text` |
| Token field names | `prompt_tokens`, `completion_tokens` | `input_tokens`, `output_tokens` |

## Section 3: Streaming Responses

Streaming sends tokens as they are generated, reducing perceived latency.

### OpenAI Streaming

```python
from openai import OpenAI

client = OpenAI()

stream = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Write a haiku about Python."}],
    stream=True,
)

full_response = ""
for chunk in stream:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)
        full_response += delta

print()  # newline at end
```

### Anthropic Streaming

```python
from anthropic import Anthropic

client = Anthropic()

full_response = ""
with client.messages.stream(
    model="claude-sonnet-4-20250514",
    max_tokens=256,
    messages=[{"role": "user", "content": "Write a haiku about Python."}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
        full_response += text

print()
```

## Section 4: Error Handling -- Rate Limits, Retries, Timeouts

Production code must handle transient failures. Both SDKs include automatic retries, but you should understand the mechanics.

### Built-in Retries

```python
from openai import OpenAI

# Both SDKs retry automatically on 429 (rate limit) and 5xx errors.
# Default: 2 retries with exponential backoff.
client = OpenAI(max_retries=3, timeout=30.0)
```

```python
from anthropic import Anthropic

client = Anthropic(max_retries=3, timeout=30.0)
```

### Manual Error Handling

```python
import openai
from openai import OpenAI

client = OpenAI()

try:
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": "Hello"}],
    )
except openai.RateLimitError as e:
    print(f"Rate limited. Retry after: {e.response.headers.get('retry-after')}")
except openai.APITimeoutError:
    print("Request timed out. Consider increasing the timeout.")
except openai.APIConnectionError:
    print("Network issue. Check your internet connection.")
except openai.AuthenticationError:
    print("Invalid API key.")
except openai.APIStatusError as e:
    print(f"API error {e.status_code}: {e.message}")
```

```python
import anthropic
from anthropic import Anthropic

client = Anthropic()

try:
    message = client.messages.create(
        model="claude-sonnet-4-20250514",
        max_tokens=256,
        messages=[{"role": "user", "content": "Hello"}],
    )
except anthropic.RateLimitError:
    print("Rate limited. Back off and retry.")
except anthropic.APITimeoutError:
    print("Request timed out.")
except anthropic.AuthenticationError:
    print("Invalid API key.")
except anthropic.APIStatusError as e:
    print(f"API error {e.status_code}: {e.message}")
```

### Custom Retry with Tenacity

```python
from tenacity import retry, stop_after_attempt, wait_exponential, retry_if_exception_type
import openai
from openai import OpenAI

client = OpenAI()

@retry(
    retry=retry_if_exception_type(openai.RateLimitError),
    wait=wait_exponential(min=1, max=60),
    stop=stop_after_attempt(5),
)
def call_openai(prompt: str) -> str:
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": prompt}],
    )
    return response.choices[0].message.content
```

## Section 5: Structured Output

Raw text is hard to parse. Both APIs offer ways to get structured responses.

### OpenAI JSON Mode

```python
from openai import OpenAI
import json

client = OpenAI()

response = client.chat.completions.create(
    model="gpt-4o",
    response_format={"type": "json_object"},
    messages=[
        {"role": "system", "content": "Respond with valid JSON only."},
        {"role": "user", "content": "List 3 Python web frameworks with name and url fields."},
    ],
)

data = json.loads(response.choices[0].message.content)
print(json.dumps(data, indent=2))
```

### Anthropic Tool Use for Structured Output

Anthropic uses the tool-use mechanism to force structured responses:

```python
from anthropic import Anthropic

client = Anthropic()

tools = [
    {
        "name": "extract_frameworks",
        "description": "Extract a list of Python web frameworks.",
        "input_schema": {
            "type": "object",
            "properties": {
                "frameworks": {
                    "type": "array",
                    "items": {
                        "type": "object",
                        "properties": {
                            "name": {"type": "string"},
                            "url": {"type": "string"},
                        },
                        "required": ["name", "url"],
                    },
                }
            },
            "required": ["frameworks"],
        },
    }
]

message = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=512,
    tools=tools,
    tool_choice={"type": "tool", "name": "extract_frameworks"},
    messages=[
        {"role": "user", "content": "List 3 Python web frameworks with name and url."},
    ],
)

# The model is forced to call the tool -- extract the structured input
tool_block = next(b for b in message.content if b.type == "tool_use")
frameworks = tool_block.input["frameworks"]
for fw in frameworks:
    print(f"{fw['name']}: {fw['url']}")
```

## Section 6: Cost Estimation

API calls cost money. Track usage to avoid surprises.

```python
# Approximate pricing (check current pricing pages for actuals)
PRICING = {
    "gpt-4o": {"input": 2.50 / 1_000_000, "output": 10.00 / 1_000_000},
    "gpt-4o-mini": {"input": 0.15 / 1_000_000, "output": 0.60 / 1_000_000},
    "claude-sonnet-4-20250514": {"input": 3.00 / 1_000_000, "output": 15.00 / 1_000_000},
    "claude-haiku-4-20250514": {"input": 0.80 / 1_000_000, "output": 4.00 / 1_000_000},
}


def estimate_cost(model: str, input_tokens: int, output_tokens: int) -> float:
    """Estimate cost in USD for a single API call."""
    rates = PRICING.get(model)
    if not rates:
        raise ValueError(f"Unknown model: {model}")
    return input_tokens * rates["input"] + output_tokens * rates["output"]


# Example after an OpenAI call
cost = estimate_cost(
    "gpt-4o",
    input_tokens=response.usage.prompt_tokens,
    output_tokens=response.usage.completion_tokens,
)
print(f"Estimated cost: ${cost:.6f}")
```

### Tracking Cumulative Costs

```python
class CostTracker:
    """Track cumulative API costs across a session."""

    def __init__(self):
        self.total_cost = 0.0
        self.call_count = 0
        self.total_input_tokens = 0
        self.total_output_tokens = 0

    def record(self, model: str, input_tokens: int, output_tokens: int):
        cost = estimate_cost(model, input_tokens, output_tokens)
        self.total_cost += cost
        self.call_count += 1
        self.total_input_tokens += input_tokens
        self.total_output_tokens += output_tokens
        return cost

    def summary(self) -> str:
        return (
            f"Calls: {self.call_count} | "
            f"Tokens: {self.total_input_tokens} in / {self.total_output_tokens} out | "
            f"Cost: ${self.total_cost:.4f}"
        )
```

## Common Mistakes

1. **Hard-coding API keys** -- Use `os.environ` or `python-dotenv`. Never commit keys to git.
2. **Ignoring rate limits** -- Always handle `RateLimitError`. Use exponential backoff, not fixed sleep.
3. **Not setting `max_tokens`** -- Without a limit, a model can generate thousands of tokens and run up costs.
4. **Forgetting `flush=True` when streaming** -- Without it, streamed output buffers and appears all at once.
5. **Parsing structured output without validation** -- Always wrap `json.loads()` in a try/except. The model can return malformed JSON.
