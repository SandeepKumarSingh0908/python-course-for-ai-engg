# Day 54 - Serving AI with FastAPI

**Module:** AI Engineering in Practice | **Time:** ~60 min (35 read + 25 lab)

> A model that only runs in a notebook is a prototype. To make AI useful, you serve it behind an HTTP API so other systems -- web apps, mobile clients, batch pipelines -- can call it. FastAPI is the de facto standard for building ML/AI APIs in Python. It is fast, async-native, and generates interactive documentation automatically. This lesson teaches you to wrap any model or LLM call behind a production-ready FastAPI endpoint.

## By the end of this lesson you will

- Build FastAPI endpoints with path parameters, query parameters, and JSON bodies
- Use Pydantic models for request/response validation and documentation
- Implement async endpoints for I/O-bound AI calls
- Serve an ML model and an LLM endpoint behind a REST API

## Section 2: Pydantic Models for Request/Response Validation

Pydantic is FastAPI's backbone. It validates input automatically and generates clear error messages.

### Request and Response Models

```python
from pydantic import BaseModel, Field


class PredictionRequest(BaseModel):
    text: str = Field(..., min_length=1, max_length=10_000, description="Text to analyze")
    model: str = Field(default="default", description="Model to use for prediction")
    temperature: float = Field(default=0.7, ge=0.0, le=2.0, description="Sampling temperature")

    model_config = {"json_schema_extra": {
        "examples": [
            {
                "text": "FastAPI makes building APIs simple and fun.",
                "model": "sentiment-v2",
                "temperature": 0.5,
            }
        ]
    }}


class PredictionResponse(BaseModel):
    label: str
    confidence: float = Field(ge=0.0, le=1.0)
    model_used: str
    tokens_used: int


class ErrorResponse(BaseModel):
    error: str
    detail: str | None = None
```

### Using Models in Endpoints

```python
from fastapi import FastAPI, HTTPException

app = FastAPI()


@app.post("/predict", response_model=PredictionResponse)
def predict(request: PredictionRequest):
    """Run sentiment analysis on the input text."""
    if len(request.text.split()) < 3:
        raise HTTPException(
            status_code=422,
            detail="Text must contain at least 3 words.",
        )

    # Mock prediction (replace with real model call)
    return PredictionResponse(
        label="positive",
        confidence=0.92,
        model_used=request.model,
        tokens_used=len(request.text.split()),
    )
```

If a client sends invalid data, FastAPI returns a 422 with clear errors:

```json
{
  "detail": [
    {
      "loc": ["body", "temperature"],
      "msg": "Input should be less than or equal to 2",
      "type": "less_than_equal"
    }
  ]
}
```

## Section 3: Async Endpoints for AI Calls

LLM API calls are I/O-bound (waiting for the network). Async endpoints let your server handle other requests while waiting.

### Sync vs Async

```python
# SYNC -- blocks the event loop while waiting for the API response
@app.post("/chat-sync")
def chat_sync(request: PredictionRequest):
    from openai import OpenAI

    client = OpenAI()
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": request.text}],
    )
    return {"reply": response.choices[0].message.content}


# ASYNC -- frees the event loop while waiting
@app.post("/chat-async")
async def chat_async(request: PredictionRequest):
    from openai import AsyncOpenAI

    client = AsyncOpenAI()
    response = await client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": request.text}],
    )
    return {"reply": response.choices[0].message.content}
```

**Rule of thumb:** If your endpoint calls an external API or database, make it `async` and use `await`. If it only does CPU work (running a local model), keep it sync -- FastAPI runs sync endpoints in a thread pool.

### Async Anthropic

```python
from anthropic import AsyncAnthropic


@app.post("/chat-anthropic")
async def chat_anthropic(request: PredictionRequest):
    client = AsyncAnthropic()
    message = await client.messages.create(
        model="claude-sonnet-4-20250514",
        max_tokens=512,
        messages=[{"role": "user", "content": request.text}],
    )
    return {"reply": message.content[0].text}
```

### Streaming Responses

For long LLM outputs, stream tokens back to the client:

```python
from fastapi.responses import StreamingResponse
from openai import AsyncOpenAI


@app.post("/chat-stream")
async def chat_stream(request: PredictionRequest):
    client = AsyncOpenAI()

    async def generate():
        stream = await client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": request.text}],
            stream=True,
        )
        async for chunk in stream:
            delta = chunk.choices[0].delta.content
            if delta:
                yield delta

    return StreamingResponse(generate(), media_type="text/plain")
```

## Section 4: Middleware, CORS, and Error Handling

### CORS (Cross-Origin Resource Sharing)

Required when a browser frontend calls your API from a different domain.

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000", "https://myapp.com"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### Request Logging Middleware

```python
import time
import logging
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request

logger = logging.getLogger("ai_service")


class LoggingMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        start = time.perf_counter()
        response = await call_next(request)
        elapsed = time.perf_counter() - start
        logger.info(
            f"{request.method} {request.url.path} "
            f"status={response.status_code} "
            f"duration={elapsed:.3f}s"
        )
        return response


app.add_middleware(LoggingMiddleware)
```

### Global Error Handling

```python
from fastapi import Request
from fastapi.responses import JSONResponse


@app.exception_handler(Exception)
async def global_exception_handler(request: Request, exc: Exception):
    logger.error(f"Unhandled error: {exc}", exc_info=True)
    return JSONResponse(
        status_code=500,
        content={"error": "Internal server error", "detail": str(exc)},
    )


# Specific error handler for rate limits
class RateLimitExceeded(Exception):
    pass


@app.exception_handler(RateLimitExceeded)
async def rate_limit_handler(request: Request, exc: RateLimitExceeded):
    return JSONResponse(
        status_code=429,
        content={"error": "Rate limit exceeded", "detail": str(exc)},
    )
```

## Section 5: Serving an ML Model

### Loading a Scikit-Learn Model at Startup

```python
import pickle
from contextlib import asynccontextmanager
from fastapi import FastAPI


# Use lifespan to load the model once at startup
@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup: load model
    with open("model.pkl", "rb") as f:
        app.state.model = pickle.load(f)
    print("Model loaded")
    yield
    # Shutdown: cleanup
    print("Shutting down")


app = FastAPI(lifespan=lifespan)


class FeatureInput(BaseModel):
    features: list[float] = Field(..., min_length=4, max_length=4)


class ModelPrediction(BaseModel):
    prediction: int
    probabilities: list[float]


@app.post("/predict-sklearn", response_model=ModelPrediction)
def predict_sklearn(input_data: FeatureInput):
    model = app.state.model
    features = [input_data.features]

    prediction = int(model.predict(features)[0])
    probabilities = model.predict_proba(features)[0].tolist()

    return ModelPrediction(
        prediction=prediction,
        probabilities=probabilities,
    )
```

### Full LLM Service Example

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field
from contextlib import asynccontextmanager
from openai import AsyncOpenAI


@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.llm_client = AsyncOpenAI()
    yield


app = FastAPI(title="LLM Service", lifespan=lifespan)


class ChatRequest(BaseModel):
    message: str = Field(..., min_length=1)
    system_prompt: str = Field(default="You are a helpful assistant.")
    model: str = Field(default="gpt-4o-mini")
    max_tokens: int = Field(default=512, ge=1, le=4096)
    temperature: float = Field(default=0.7, ge=0.0, le=2.0)


class ChatResponse(BaseModel):
    reply: str
    model: str
    input_tokens: int
    output_tokens: int


@app.post("/chat", response_model=ChatResponse)
async def chat(request: ChatRequest):
    try:
        response = await app.state.llm_client.chat.completions.create(
            model=request.model,
            messages=[
                {"role": "system", "content": request.system_prompt},
                {"role": "user", "content": request.message},
            ],
            max_tokens=request.max_tokens,
            temperature=request.temperature,
        )
    except Exception as e:
        raise HTTPException(status_code=502, detail=f"LLM API error: {e}")

    choice = response.choices[0]
    return ChatResponse(
        reply=choice.message.content,
        model=response.model,
        input_tokens=response.usage.prompt_tokens,
        output_tokens=response.usage.completion_tokens,
    )
```

## Common Mistakes

1. **Using sync functions for I/O-bound work** -- If your endpoint calls an external API, use `async def` and `await`. Otherwise, you block the event loop.
2. **Loading the model inside the endpoint** -- Loading a model takes seconds. Use `lifespan` to load once at startup and store on `app.state`.
3. **Not validating input** -- Without Pydantic models, bad input causes cryptic 500 errors instead of clear 422 validation errors.
4. **Forgetting CORS** -- Browser-based frontends will fail silently without CORS headers. Add the middleware early.
5. **No error handling for LLM calls** -- LLM APIs fail regularly (rate limits, timeouts, content filters). Always wrap calls in try/except and return meaningful error responses.

## Solutions

### Solution 1: Multi-endpoint AI API (app.py)

```python
import os
import json
import time
import logging
from collections import deque
from contextlib import asynccontextmanager
from datetime import datetime, timezone

from fastapi import FastAPI, HTTPException, Request
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import JSONResponse
from pydantic import BaseModel, Field
from openai import AsyncOpenAI

logger = logging.getLogger("ai_api")
logging.basicConfig(level=logging.INFO)

# In-memory history store (last 10 requests)
history: deque = deque(maxlen=10)


# --- Pydantic models ---

class SummarizeRequest(BaseModel):
    text: str = Field(..., min_length=10, max_length=50_000)
    max_sentences: int = Field(default=3, ge=1, le=20)


class SummarizeResponse(BaseModel):
    summary: str
    input_length: int
    output_length: int


class ClassifyRequest(BaseModel):
    text: str = Field(..., min_length=1, max_length=10_000)
    categories: list[str] = Field(..., min_length=2)


class ClassifyResponse(BaseModel):
    category: str
    confidence: float = Field(ge=0.0, le=1.0)


class ExtractRequest(BaseModel):
    text: str = Field(..., min_length=1, max_length=10_000)
    fields: list[str] = Field(..., min_length=1)


class ExtractResponse(BaseModel):
    entities: dict[str, str | None]


# --- Lifespan ---

@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.llm = AsyncOpenAI(api_key=os.getenv("OPENAI_API_KEY"))
    yield


app = FastAPI(title="AI Toolkit API", lifespan=lifespan)

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)


# --- Logging middleware ---

@app.middleware("http")
async def log_requests(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)
    elapsed = (time.perf_counter() - start) * 1000
    logger.info(f"{request.method} {request.url.path} {response.status_code} {elapsed:.1f}ms")
    return response


# --- Global error handler ---

@app.exception_handler(Exception)
async def global_error_handler(request: Request, exc: Exception):
    logger.error(f"Unhandled error: {exc}", exc_info=True)
    return JSONResponse(status_code=500, content={"error": "Internal server error", "detail": str(exc)})


# --- Endpoints ---

@app.post("/summarize", response_model=SummarizeResponse)
async def summarize(request: SummarizeRequest):
    prompt = (
        f"Summarize the following text in at most {request.max_sentences} sentences. "
        f"Be concise and preserve key facts.\n\nText:\n{request.text}\n\nSummary:"
    )
    try:
        resp = await app.state.llm.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": prompt}],
            max_tokens=512,
            temperature=0.3,
        )
    except Exception as e:
        raise HTTPException(status_code=502, detail=f"LLM error: {e}")

    summary = resp.choices[0].message.content.strip()
    result = SummarizeResponse(
        summary=summary,
        input_length=len(request.text),
        output_length=len(summary),
    )
    history.append({"endpoint": "/summarize", "input": request.text[:100], "output": summary[:100],
                     "ts": datetime.now(timezone.utc).isoformat()})
    return result


@app.post("/classify", response_model=ClassifyResponse)
async def classify(request: ClassifyRequest):
    categories_str = ", ".join(request.categories)
    prompt = (
        f"Classify the following text into exactly one of these categories: {categories_str}.\n"
        f"Respond with JSON only: {{\"category\": \"<chosen>\", \"confidence\": <0.0-1.0>}}\n\n"
        f"Text: {request.text}"
    )
    try:
        resp = await app.state.llm.chat.completions.create(
            model="gpt-4o-mini",
            messages=[
                {"role": "system", "content": "You are a text classifier. Respond with valid JSON only."},
                {"role": "user", "content": prompt},
            ],
            response_format={"type": "json_object"},
            max_tokens=64,
            temperature=0.0,
        )
    except Exception as e:
        raise HTTPException(status_code=502, detail=f"LLM error: {e}")

    import json as _json
    try:
        data = _json.loads(resp.choices[0].message.content)
        result = ClassifyResponse(category=data["category"], confidence=float(data["confidence"]))
    except Exception:
        raise HTTPException(status_code=502, detail="LLM returned malformed JSON")

    history.append({"endpoint": "/classify", "input": request.text[:100], "output": result.category,
                     "ts": datetime.now(timezone.utc).isoformat()})
    return result


@app.post("/extract", response_model=ExtractResponse)
async def extract(request: ExtractRequest):
    fields_str = ", ".join(request.fields)
    prompt = (
        f"Extract the following fields from the text: {fields_str}.\n"
        f"Return JSON with each field as a key. Use null if the field is not found.\n\n"
        f"Text: {request.text}"
    )
    try:
        resp = await app.state.llm.chat.completions.create(
            model="gpt-4o-mini",
            messages=[
                {"role": "system", "content": "You are a data extractor. Respond with valid JSON only."},
                {"role": "user", "content": prompt},
            ],
            response_format={"type": "json_object"},
            max_tokens=256,
            temperature=0.0,
        )
    except Exception as e:
        raise HTTPException(status_code=502, detail=f"LLM error: {e}")

    import json as _json
    try:
        entities = _json.loads(resp.choices[0].message.content)
    except Exception:
        raise HTTPException(status_code=502, detail="LLM returned malformed JSON")

    result = ExtractResponse(entities=entities)
    history.append({"endpoint": "/extract", "input": request.text[:100], "output": str(entities)[:100],
                     "ts": datetime.now(timezone.utc).isoformat()})
    return result


@app.get("/history")
def get_history():
    return {"history": list(history)}
```

### Solution 2: Tests (test_app.py)

```python
from unittest.mock import AsyncMock, MagicMock, patch
from fastapi.testclient import TestClient

# Import after mocking so lifespan does not call real OpenAI
with patch("openai.AsyncOpenAI"):
    from app import app

client = TestClient(app)


def _mock_completion(content: str):
    """Build a fake OpenAI completion response."""
    choice = MagicMock()
    choice.message.content = content
    resp = MagicMock()
    resp.choices = [choice]
    return resp


def test_summarize_valid():
    with patch.object(app.state, "llm", create=True) as mock_llm:
        mock_llm.chat.completions.create = AsyncMock(
            return_value=_mock_completion("Python is a high-level language.")
        )
        response = client.post("/summarize", json={"text": "Python is a great language for many tasks.", "max_sentences": 1})
    assert response.status_code == 200
    assert "summary" in response.json()


def test_summarize_too_short():
    response = client.post("/summarize", json={"text": "Hi", "max_sentences": 1})
    assert response.status_code == 422


def test_classify_valid():
    with patch.object(app.state, "llm", create=True) as mock_llm:
        mock_llm.chat.completions.create = AsyncMock(
            return_value=_mock_completion('{"category": "positive", "confidence": 0.95}')
        )
        response = client.post("/classify", json={"text": "I love this product!", "categories": ["positive", "negative"]})
    assert response.status_code == 200
    assert response.json()["category"] in ["positive", "negative"]


def test_classify_too_few_categories():
    response = client.post("/classify", json={"text": "Some text", "categories": ["only_one"]})
    assert response.status_code == 422


def test_extract_valid():
    with patch.object(app.state, "llm", create=True) as mock_llm:
        mock_llm.chat.completions.create = AsyncMock(
            return_value=_mock_completion('{"name": "Alice", "age": "30"}')
        )
        response = client.post("/extract", json={"text": "Alice is 30 years old.", "fields": ["name", "age"]})
    assert response.status_code == 200
    assert "entities" in response.json()


def test_extract_no_fields():
    response = client.post("/extract", json={"text": "Some text", "fields": []})
    assert response.status_code == 422


def test_history():
    response = client.get("/history")
    assert response.status_code == 200
    assert "history" in response.json()
```
