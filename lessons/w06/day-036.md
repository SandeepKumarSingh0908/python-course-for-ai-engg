## Section 1: The Object-Oriented Interface

Matplotlib has two interfaces. The *pyplot* shortcut (`plt.plot(...)`) is fine for
quick one-off plots, but production code and notebooks benefit from the **OO interface**
because it makes every object explicit and avoids hidden global state.

```python
import matplotlib.pyplot as plt
import numpy as np

# Always start here: create a Figure and one or more Axes
fig, ax = plt.subplots()          # 1 figure, 1 axes
ax.plot([1, 2, 3], [10, 20, 15])  # draw on the axes
ax.set_title("My First OO Plot")
ax.set_xlabel("X")
ax.set_ylabel("Y")
plt.show()
```

### Key objects

| Object   | What it is                                  |
|----------|---------------------------------------------|
| `Figure` | The whole window / image canvas             |
| `Axes`   | One individual plot area inside the figure  |
| `Axis`   | The x-axis or y-axis (ticks, limits, label) |
| `Artist` | Everything drawn on the figure (lines, text)|

Think of `Figure` as the frame and `Axes` as the canvas inside it. A figure can hold
many axes objects (subplots), but each axes belongs to exactly one figure.

```python
fig, ax = plt.subplots(figsize=(8, 4))   # width=8, height=4 inches
print(type(fig))   # <class 'matplotlib.figure.Figure'>
print(type(ax))    # <class 'matplotlib.axes._subplots.AxesSubplot'>
```

## Section 2: Core Plot Types

### Line plot

The default and most common plot. Ideal for time series and training curves.

```python
epochs = np.arange(1, 21)
train_loss = 1.0 / np.sqrt(epochs) + np.random.normal(0, 0.02, size=20)
val_loss   = 1.0 / np.sqrt(epochs) + 0.05 + np.random.normal(0, 0.03, size=20)

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(epochs, train_loss, label="Train Loss", color="steelblue", linewidth=2)
ax.plot(epochs, val_loss,   label="Val Loss",   color="tomato",    linestyle="--")
ax.set_xlabel("Epoch")
ax.set_ylabel("Loss")
ax.set_title("Training Curve")
ax.legend()
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

### Scatter plot

Great for showing the relationship between two features.

```python
np.random.seed(42)
x = np.random.randn(200)
y = 0.6 * x + np.random.randn(200) * 0.4

fig, ax = plt.subplots()
ax.scatter(x, y, alpha=0.6, edgecolors="k", linewidths=0.5, s=40)
ax.set_xlabel("Feature A")
ax.set_ylabel("Feature B")
ax.set_title("Scatter Plot of Two Features")
plt.show()
```

### Bar chart

Useful for comparing categorical values such as model accuracy across experiments.

```python
models = ["Logistic Reg", "Random Forest", "XGBoost", "MLP", "Transformer"]
accuracy = [0.82, 0.89, 0.91, 0.90, 0.93]

fig, ax = plt.subplots(figsize=(8, 4))
bars = ax.bar(models, accuracy, color=["#4c72b0", "#55a868", "#c44e52", "#8172b2", "#ccb974"])
ax.set_ylabel("Accuracy")
ax.set_title("Model Comparison")
ax.set_ylim(0.75, 0.96)

# Add value labels on top of each bar
for bar, acc in zip(bars, accuracy):
    ax.text(bar.get_x() + bar.get_width() / 2, bar.get_height() + 0.005,
            f"{acc:.2f}", ha="center", va="bottom", fontsize=10)

plt.tight_layout()
plt.show()
```

### Histogram

Essential for understanding feature distributions before training.

```python
np.random.seed(7)
data = np.random.normal(loc=50, scale=12, size=1000)

fig, ax = plt.subplots()
ax.hist(data, bins=30, color="steelblue", edgecolor="white", alpha=0.8)
ax.axvline(data.mean(), color="red", linestyle="--", label=f"Mean = {data.mean():.1f}")
ax.set_xlabel("Value")
ax.set_ylabel("Frequency")
ax.set_title("Feature Distribution")
ax.legend()
plt.show()
```

### Pie chart

Use sparingly -- mainly for showing proportions of a small number of categories.

```python
labels = ["Training", "Validation", "Test"]
sizes = [70, 15, 15]
explode = (0.05, 0, 0)

fig, ax = plt.subplots()
ax.pie(sizes, explode=explode, labels=labels, autopct="%1.0f%%",
       startangle=90, colors=["#4c72b0", "#55a868", "#c44e52"])
ax.set_title("Dataset Split")
plt.show()
```

## Section 3: Customization

```python
# Customizing colors, fonts, and styles
fig, ax = plt.subplots(figsize=(7, 4))

x = np.linspace(0, 2 * np.pi, 100)
ax.plot(x, np.sin(x), color="#e74c3c", linewidth=2, label="sin(x)")
ax.plot(x, np.cos(x), color="#3498db", linewidth=2, label="cos(x)")

ax.set_title("Trigonometric Functions", fontsize=14, fontweight="bold")
ax.set_xlabel("Radians", fontsize=12)
ax.set_ylabel("Amplitude", fontsize=12)
ax.legend(loc="upper right", frameon=True, shadow=True)
ax.set_xlim(0, 2 * np.pi)
ax.set_ylim(-1.3, 1.3)
ax.tick_params(axis="both", labelsize=10)
ax.grid(True, linestyle=":", alpha=0.5)
plt.tight_layout()
plt.show()
```

## Section 4: Subplots

When you need side-by-side comparisons -- for instance, plotting loss and accuracy on
the same figure.

```python
np.random.seed(42)
epochs = np.arange(1, 31)
loss = 1.2 * np.exp(-0.1 * epochs) + np.random.normal(0, 0.02, 30)
accuracy = 1 - 0.8 * np.exp(-0.12 * epochs) + np.random.normal(0, 0.01, 30)

fig, axes = plt.subplots(nrows=1, ncols=2, figsize=(12, 4))

# Left plot: loss
axes[0].plot(epochs, loss, color="tomato")
axes[0].set_title("Training Loss")
axes[0].set_xlabel("Epoch")
axes[0].set_ylabel("Loss")
axes[0].grid(True, alpha=0.3)

# Right plot: accuracy
axes[1].plot(epochs, accuracy, color="seagreen")
axes[1].set_title("Training Accuracy")
axes[1].set_xlabel("Epoch")
axes[1].set_ylabel("Accuracy")
axes[1].grid(True, alpha=0.3)

fig.suptitle("Model Training Dashboard", fontsize=14, fontweight="bold")
plt.tight_layout()
plt.show()
```

### 2D grid of subplots

```python
fig, axes = plt.subplots(nrows=2, ncols=2, figsize=(10, 8))

data_sets = [
    np.random.normal(0, 1, 500),
    np.random.exponential(1, 500),
    np.random.uniform(-2, 2, 500),
    np.random.poisson(5, 500),
]
titles = ["Normal", "Exponential", "Uniform", "Poisson"]

for ax, data, title in zip(axes.flat, data_sets, titles):
    ax.hist(data, bins=25, color="steelblue", edgecolor="white")
    ax.set_title(title)

fig.suptitle("Distribution Comparison", fontsize=14, fontweight="bold")
plt.tight_layout()
plt.show()
```

## Section 5: Saving Figures

```python
fig, ax = plt.subplots(figsize=(6, 4))
ax.plot([1, 2, 3], [4, 5, 6])
ax.set_title("Save Me")

# PNG (raster) -- good for reports and dashboards
fig.savefig("plot.png", dpi=150, bbox_inches="tight")

# SVG (vector) -- good for papers and web
fig.savefig("plot.svg", bbox_inches="tight")

# PDF (vector) -- good for LaTeX documents
fig.savefig("plot.pdf", bbox_inches="tight")

# Transparent background
fig.savefig("plot_transparent.png", dpi=150, transparent=True, bbox_inches="tight")
```

> **Tip:** Always pass `bbox_inches="tight"` to avoid clipped labels.

## Section 6: AI Engineering Patterns

### Confusion matrix heatmap

```python
from sklearn.metrics import confusion_matrix
import matplotlib.pyplot as plt
import numpy as np

y_true = [0, 0, 0, 1, 1, 1, 2, 2, 2]
y_pred = [0, 1, 0, 1, 1, 2, 2, 2, 0]
cm = confusion_matrix(y_true, y_pred)
labels = ["Cat", "Dog", "Bird"]

fig, ax = plt.subplots()
im = ax.imshow(cm, cmap="Blues")

ax.set_xticks(range(len(labels)))
ax.set_yticks(range(len(labels)))
ax.set_xticklabels(labels)
ax.set_yticklabels(labels)
ax.set_xlabel("Predicted")
ax.set_ylabel("Actual")
ax.set_title("Confusion Matrix")

# Annotate each cell
for i in range(len(labels)):
    for j in range(len(labels)):
        ax.text(j, i, str(cm[i, j]), ha="center", va="center",
                color="white" if cm[i, j] > cm.max() / 2 else "black")

fig.colorbar(im)
plt.tight_layout()
plt.show()
```

### Real-time training plot pattern

```python
# Pseudocode pattern -- works in Jupyter with %matplotlib inline
fig, ax = plt.subplots()
losses = []

for epoch in range(50):
    loss = 1.0 / (epoch + 1) + np.random.normal(0, 0.01)
    losses.append(loss)
    ax.clear()
    ax.plot(losses, color="steelblue")
    ax.set_xlabel("Epoch")
    ax.set_ylabel("Loss")
    ax.set_title(f"Epoch {epoch + 1} | Loss {loss:.4f}")
    plt.pause(0.05)    # non-blocking update

plt.show()
```

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Using `plt.plot()` everywhere (pyplot interface) | Use `fig, ax = plt.subplots()` then `ax.plot()` |
| Overlapping labels in subplots | Call `plt.tight_layout()` or `fig.tight_layout()` |
| Forgetting `plt.show()` in scripts | Always call it; in Jupyter use `%matplotlib inline` |
| Labels clipped when saving | Pass `bbox_inches="tight"` to `savefig()` |
| Creating huge figures in memory loops | Close figures with `plt.close(fig)` after saving |

<details>
<summary>Answers</summary>

1. A `Figure` is the top-level container (the whole image). An `Axes` is a single plot
   area within the figure. One figure can contain many axes.
2. `fig, axes = plt.subplots(nrows=1, ncols=3)`
3. `ax.legend()` -- it automatically picks up artists that have a `label` keyword set.
4. `bbox_inches="tight"`
5. The OO interface avoids hidden global state, makes it explicit which axes you are
   drawing on, and is easier to manage when you have multiple subplots or figures.
