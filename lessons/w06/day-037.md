## Section 1: Seaborn Fundamentals

Seaborn wraps matplotlib and adds:
- Attractive default themes
- Built-in statistical aggregation
- Tight integration with pandas DataFrames

```python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

# Seaborn ships with example datasets
tips = sns.load_dataset("tips")
print(tips.head())
#    total_bill   tip     sex smoker  day    time  size
# 0       16.99  1.01  Female     No  Sun  Dinner     2
# 1       10.34  1.66    Male     No  Sun  Dinner     3
# ...
```

### Figure-level vs. Axes-level

Seaborn offers two layers:

| Level | Functions | Returns | When to use |
|-------|-----------|---------|-------------|
| Figure-level | `relplot`, `catplot`, `displot` | `FacetGrid` | Quick multi-panel plots |
| Axes-level | `scatterplot`, `boxplot`, `histplot` | matplotlib `Axes` | Embedding in custom figures |

```python
# Figure-level: creates its own figure
g = sns.relplot(data=tips, x="total_bill", y="tip", hue="smoker",
                col="time", kind="scatter", height=4, aspect=1.2)
g.fig.suptitle("Tips by Meal Time", y=1.02)
plt.show()

# Axes-level: you provide the axes
fig, ax = plt.subplots(figsize=(7, 4))
sns.scatterplot(data=tips, x="total_bill", y="tip", hue="smoker", ax=ax)
ax.set_title("Tips vs Total Bill")
plt.show()
```

## Section 2: Distribution Plots

Understanding the distribution of each feature is EDA step one.

### Histogram and KDE

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

# Histogram with KDE overlay
sns.histplot(data=tips, x="total_bill", kde=True, bins=25, ax=axes[0])
axes[0].set_title("Total Bill Distribution")

# KDE only, split by category
sns.kdeplot(data=tips, x="tip", hue="time", fill=True, alpha=0.4, ax=axes[1])
axes[1].set_title("Tip Distribution by Meal")

plt.tight_layout()
plt.show()
```

### displot (figure-level)

```python
g = sns.displot(data=tips, x="total_bill", hue="sex", kind="kde",
                fill=True, height=4, aspect=1.5)
g.set_axis_labels("Total Bill ($)", "Density")
plt.show()
```

## Section 3: Categorical Plots

### Box plot

Shows median, quartiles, and outliers -- perfect for spotting skew in features.

```python
fig, ax = plt.subplots(figsize=(8, 4))
sns.boxplot(data=tips, x="day", y="total_bill", hue="sex",
            palette="Set2", ax=ax)
ax.set_title("Total Bill by Day and Gender")
plt.tight_layout()
plt.show()
```

### Violin plot

Like a box plot but shows the full density shape.

```python
fig, ax = plt.subplots(figsize=(8, 4))
sns.violinplot(data=tips, x="day", y="total_bill", hue="smoker",
               split=True, inner="quart", palette="muted", ax=ax)
ax.set_title("Total Bill Distribution by Day")
plt.tight_layout()
plt.show()
```

### Bar plot (with error bars)

Seaborn's `barplot` computes the mean and a 95% confidence interval by default.

```python
fig, ax = plt.subplots(figsize=(7, 4))
sns.barplot(data=tips, x="day", y="tip", hue="sex",
            palette="coolwarm", errorbar="sd", ax=ax)
ax.set_title("Average Tip by Day (with Std Dev)")
plt.tight_layout()
plt.show()
```

### catplot (figure-level)

```python
g = sns.catplot(data=tips, x="day", y="total_bill", hue="smoker",
                kind="swarm", col="time", height=4, aspect=1)
g.fig.suptitle("Swarm Plot by Day and Time", y=1.02)
plt.show()
```

## Section 4: Relational and Matrix Plots

### Pair plot

The fastest way to see every pairwise feature relationship.

```python
# Use the iris dataset for a classic ML example
iris = sns.load_dataset("iris")

g = sns.pairplot(iris, hue="species", diag_kind="kde",
                 plot_kws={"alpha": 0.6, "s": 30})
g.fig.suptitle("Iris Feature Pair Plot", y=1.02)
plt.show()
```

### Heatmap

Essential for correlation matrices, confusion matrices, and attention weights.

```python
# Correlation matrix heatmap
np.random.seed(42)
df = pd.DataFrame(np.random.randn(200, 5),
                  columns=["feature_a", "feature_b", "feature_c",
                           "feature_d", "target"])
# Inject some correlation
df["feature_a"] = df["target"] * 0.8 + np.random.randn(200) * 0.3
df["feature_b"] = df["target"] * -0.5 + np.random.randn(200) * 0.5

corr = df.corr()

fig, ax = plt.subplots(figsize=(7, 6))
sns.heatmap(corr, annot=True, fmt=".2f", cmap="coolwarm",
            center=0, square=True, linewidths=0.5, ax=ax)
ax.set_title("Feature Correlation Matrix")
plt.tight_layout()
plt.show()
```

### Cluster map

Groups similar rows and columns together using hierarchical clustering.

```python
# Simulated attention weights or feature importance matrix
data = pd.DataFrame(
    np.random.rand(8, 6),
    index=[f"sample_{i}" for i in range(8)],
    columns=[f"feat_{j}" for j in range(6)]
)

g = sns.clustermap(data, cmap="viridis", figsize=(7, 7),
                   linewidths=0.5, annot=True, fmt=".2f")
g.fig.suptitle("Clustered Feature Heatmap", y=1.02)
plt.show()
```

## Section 6: Combining Seaborn and Matplotlib

The real power comes from mixing both libraries. Use seaborn for the statistical plot,
then tweak with matplotlib.

```python
fig, axes = plt.subplots(1, 3, figsize=(16, 5))

# Plot 1: Seaborn histogram + matplotlib annotation
sns.histplot(data=tips, x="total_bill", bins=20, ax=axes[0])
mean_val = tips["total_bill"].mean()
axes[0].axvline(mean_val, color="red", linestyle="--")
axes[0].annotate(f"Mean: ${mean_val:.2f}", xy=(mean_val, 25),
                 xytext=(mean_val + 5, 30),
                 arrowprops=dict(arrowstyle="->", color="red"),
                 fontsize=10, color="red")
axes[0].set_title("Bill Distribution")

# Plot 2: Seaborn scatter + matplotlib regression line
sns.scatterplot(data=tips, x="total_bill", y="tip", alpha=0.6, ax=axes[1])
m, b = np.polyfit(tips["total_bill"], tips["tip"], 1)
x_line = np.linspace(tips["total_bill"].min(), tips["total_bill"].max(), 100)
axes[1].plot(x_line, m * x_line + b, color="red", linewidth=2,
             label=f"y = {m:.2f}x + {b:.2f}")
axes[1].legend()
axes[1].set_title("Tips vs Bill (with Fit)")

# Plot 3: Seaborn violin + matplotlib styling
sns.violinplot(data=tips, x="day", y="total_bill", palette="pastel", ax=axes[2])
axes[2].set_title("Bill by Day")
axes[2].set_ylabel("Total Bill ($)")

fig.suptitle("Combined Seaborn + Matplotlib Dashboard", fontsize=14, fontweight="bold")
plt.tight_layout()
plt.show()
```

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Calling `sns.set_theme()` and not resetting | Use `with sns.axes_style("whitegrid"):` for temporary styles |
| Mixing figure-level functions with `ax=` | Figure-level (`relplot`, `catplot`) ignore `ax=`; use axes-level equivalents |
| Heatmap labels overlapping | Rotate with `ax.set_xticklabels(ax.get_xticklabels(), rotation=45, ha="right")` |
| Forgetting `dropna()` before plotting | Seaborn often warns or misplots with NaN; clean first |
| Pair plot too slow on large datasets | Sample first: `df.sample(500)` |
