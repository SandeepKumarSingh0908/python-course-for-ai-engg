# Day 39 - Databases with Python

**Module:** Visualization, APIs & Testing | **Time:** ~60 min (35 read + 25 lab)

> ML projects generate mountains of structured data: feature tables, experiment
> configurations, evaluation metrics, model metadata. Flat files (CSV, JSON) stop
> scaling once you need filtering, joining, or concurrent access. Databases give you
> all of that plus ACID guarantees. Every AI engineer needs to know how to read from
> and write to a database from Python.

## By the end of this lesson you will

- Use the built-in `sqlite3` module to create tables, insert data, and query results
- Write parameterized queries to prevent SQL injection
- Set up SQLAlchemy with an ORM to map Python classes to database tables

## Section 1: sqlite3 -- The Built-in Database

SQLite ships with Python -- no server to install. It stores an entire database in a
single file (or in memory with `":memory:"`).

```python
import sqlite3

# Connect (creates the file if it does not exist)
conn = sqlite3.connect("experiments.db")
cursor = conn.cursor()

# Create a table
cursor.execute("""
    CREATE TABLE IF NOT EXISTS experiments (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        model TEXT NOT NULL,
        accuracy REAL,
        f1_score REAL,
        created_at TEXT DEFAULT CURRENT_TIMESTAMP
    )
""")
conn.commit()
```

### Insert data

```python
# Single insert
cursor.execute(
    "INSERT INTO experiments (name, model, accuracy, f1_score) VALUES (?, ?, ?, ?)",
    ("baseline_v1", "logistic_regression", 0.82, 0.79)
)

# Batch insert with executemany
experiments = [
    ("rf_v1",    "random_forest",  0.89, 0.87),
    ("xgb_v1",  "xgboost",        0.91, 0.90),
    ("mlp_v1",  "neural_network", 0.88, 0.86),
    ("bert_v1", "transformer",    0.93, 0.92),
]
cursor.executemany(
    "INSERT INTO experiments (name, model, accuracy, f1_score) VALUES (?, ?, ?, ?)",
    experiments
)
conn.commit()
```

### Query data

```python
# Fetch all rows
cursor.execute("SELECT * FROM experiments ORDER BY accuracy DESC")
rows = cursor.fetchall()
for row in rows:
    print(row)

# Fetch one row
cursor.execute("SELECT * FROM experiments WHERE accuracy > ?", (0.90,))
best = cursor.fetchone()
print(f"Best experiment: {best}")

# Use row_factory for dict-like access
conn.row_factory = sqlite3.Row
cursor = conn.cursor()
cursor.execute("SELECT name, model, accuracy FROM experiments WHERE accuracy > ?", (0.85,))
for row in cursor.fetchall():
    print(f"{row['name']:15s} | {row['model']:20s} | acc={row['accuracy']:.2f}")
```

### Update and delete

```python
# Update
cursor.execute(
    "UPDATE experiments SET accuracy = ?, f1_score = ? WHERE name = ?",
    (0.84, 0.81, "baseline_v1")
)

# Delete
cursor.execute("DELETE FROM experiments WHERE accuracy < ?", (0.85,))
conn.commit()
```

### Clean up

```python
conn.close()
```

## Section 2: Parameterized Queries

**Never** build SQL with string formatting. This invites SQL injection.

```python
# WRONG -- vulnerable to SQL injection
name = "test'; DROP TABLE experiments; --"
cursor.execute(f"SELECT * FROM experiments WHERE name = '{name}'")  # DANGEROUS

# RIGHT -- parameterized query
cursor.execute("SELECT * FROM experiments WHERE name = ?", (name,))
```

The `?` placeholder tells SQLite to treat the value as data, never as SQL syntax.
Different databases use different placeholder styles:

| Database | Placeholder |
|----------|-------------|
| SQLite   | `?`         |
| PostgreSQL (psycopg2) | `%s` |
| MySQL (mysql-connector) | `%s` |
| SQLAlchemy | `:name` (named) |

## Section 3: Context Managers

Use context managers so connections close properly even when errors occur.

```python
import sqlite3

def log_experiment(db_path: str, name: str, model: str, accuracy: float, f1: float):
    """Insert an experiment record safely."""
    with sqlite3.connect(db_path) as conn:
        conn.execute(
            "INSERT INTO experiments (name, model, accuracy, f1_score) VALUES (?, ?, ?, ?)",
            (name, model, accuracy, f1)
        )
        # conn.commit() is called automatically if no exception occurs

def get_top_experiments(db_path: str, limit: int = 5) -> list[dict]:
    """Retrieve the top experiments by accuracy."""
    with sqlite3.connect(db_path) as conn:
        conn.row_factory = sqlite3.Row
        cursor = conn.execute(
            "SELECT name, model, accuracy, f1_score FROM experiments "
            "ORDER BY accuracy DESC LIMIT ?",
            (limit,)
        )
        return [dict(row) for row in cursor.fetchall()]

# Usage
log_experiment("experiments.db", "new_run", "xgboost", 0.94, 0.93)
top = get_top_experiments("experiments.db", limit=3)
for exp in top:
    print(exp)
```

## Section 4: Integrating with pandas

Pandas can read from and write to SQL databases directly.

```python
import pandas as pd
import sqlite3

conn = sqlite3.connect("experiments.db")

# Read SQL into a DataFrame
df = pd.read_sql_query("SELECT * FROM experiments", conn)
print(df)
print(df.describe())

# Write a DataFrame to a table
new_data = pd.DataFrame({
    "name": ["svm_v1", "knn_v1"],
    "model": ["svm", "knn"],
    "accuracy": [0.85, 0.80],
    "f1_score": [0.83, 0.78]
})
new_data.to_sql("experiments", conn, if_exists="append", index=False)

# Verify
df = pd.read_sql_query("SELECT * FROM experiments ORDER BY accuracy DESC", conn)
print(df)

conn.close()
```

## Section 5: SQLAlchemy Basics

SQLAlchemy is the most popular Python database toolkit. It provides:
- **Core:** SQL expression language (programmatic SQL building)
- **ORM:** Map Python classes to database tables

### Engine and connection

```python
from sqlalchemy import create_engine, text

# SQLite
engine = create_engine("sqlite:///ml_experiments.db", echo=False)

# For PostgreSQL (if installed):
# engine = create_engine("postgresql://user:pass@localhost/mydb")

# Raw SQL via Core
with engine.connect() as conn:
    conn.execute(text("""
        CREATE TABLE IF NOT EXISTS models (
            id INTEGER PRIMARY KEY,
            name TEXT NOT NULL,
            framework TEXT,
            params INTEGER,
            accuracy REAL
        )
    """))
    conn.commit()
```

### ORM: Defining models

```python
from sqlalchemy import Column, Integer, String, Float, DateTime
from sqlalchemy.orm import declarative_base, Session
from datetime import datetime

Base = declarative_base()

class Experiment(Base):
    __tablename__ = "orm_experiments"

    id = Column(Integer, primary_key=True, autoincrement=True)
    name = Column(String, nullable=False)
    model_type = Column(String, nullable=False)
    accuracy = Column(Float)
    f1_score = Column(Float)
    created_at = Column(DateTime, default=datetime.utcnow)

    def __repr__(self):
        return (f"Experiment(name={self.name!r}, model={self.model_type!r}, "
                f"acc={self.accuracy}, f1={self.f1_score})")

# Create the table
Base.metadata.create_all(engine)
```

### ORM: CRUD operations

```python
from sqlalchemy.orm import Session

# CREATE
with Session(engine) as session:
    exp = Experiment(name="bert_finetune_v2", model_type="transformer",
                     accuracy=0.945, f1_score=0.938)
    session.add(exp)

    # Batch insert
    session.add_all([
        Experiment(name="rf_tuned", model_type="random_forest",
                   accuracy=0.910, f1_score=0.900),
        Experiment(name="xgb_tuned", model_type="xgboost",
                   accuracy=0.925, f1_score=0.918),
    ])
    session.commit()

# READ
with Session(engine) as session:
    # All experiments with accuracy > 0.90
    results = (
        session.query(Experiment)
        .filter(Experiment.accuracy > 0.90)
        .order_by(Experiment.accuracy.desc())
        .all()
    )
    for exp in results:
        print(exp)

    # Single lookup
    best = (
        session.query(Experiment)
        .order_by(Experiment.accuracy.desc())
        .first()
    )
    print(f"\nBest: {best}")

# UPDATE
with Session(engine) as session:
    exp = session.query(Experiment).filter_by(name="rf_tuned").first()
    if exp:
        exp.accuracy = 0.915
        session.commit()

# DELETE
with Session(engine) as session:
    exp = session.query(Experiment).filter_by(name="rf_tuned").first()
    if exp:
        session.delete(exp)
        session.commit()
```

## Section 6: AI Engineering Patterns

### Experiment tracker

```python
import sqlite3
from datetime import datetime

class ExperimentTracker:
    """Lightweight experiment tracker backed by SQLite."""

    def __init__(self, db_path: str = "tracker.db"):
        self.conn = sqlite3.connect(db_path)
        self.conn.row_factory = sqlite3.Row
        self._create_tables()

    def _create_tables(self):
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS runs (
                run_id INTEGER PRIMARY KEY AUTOINCREMENT,
                experiment TEXT NOT NULL,
                hyperparams TEXT,
                metrics TEXT,
                created_at TEXT DEFAULT CURRENT_TIMESTAMP
            )
        """)
        self.conn.commit()

    def log_run(self, experiment: str, hyperparams: dict, metrics: dict) -> int:
        import json
        cursor = self.conn.execute(
            "INSERT INTO runs (experiment, hyperparams, metrics) VALUES (?, ?, ?)",
            (experiment, json.dumps(hyperparams), json.dumps(metrics))
        )
        self.conn.commit()
        return cursor.lastrowid

    def get_best_run(self, experiment: str, metric: str = "accuracy") -> dict:
        import json
        cursor = self.conn.execute(
            "SELECT * FROM runs WHERE experiment = ? ORDER BY run_id DESC",
            (experiment,)
        )
        best = None
        best_val = -1
        for row in cursor.fetchall():
            metrics = json.loads(row["metrics"])
            val = metrics.get(metric, 0)
            if val > best_val:
                best_val = val
                best = dict(row)
        if best:
            best["hyperparams"] = json.loads(best["hyperparams"])
            best["metrics"] = json.loads(best["metrics"])
        return best

    def close(self):
        self.conn.close()

# Usage
tracker = ExperimentTracker()
tracker.log_run("sentiment_v1", {"lr": 0.001, "epochs": 10}, {"accuracy": 0.91, "f1": 0.89})
tracker.log_run("sentiment_v1", {"lr": 0.0005, "epochs": 20}, {"accuracy": 0.93, "f1": 0.92})

best = tracker.get_best_run("sentiment_v1")
print(f"Best run: {best}")
tracker.close()
```

### Feature store pattern

```python
import sqlite3
import json
import numpy as np

def create_feature_store(db_path: str = "features.db"):
    """Create a simple feature store."""
    conn = sqlite3.connect(db_path)
    conn.execute("""
        CREATE TABLE IF NOT EXISTS features (
            entity_id TEXT NOT NULL,
            feature_name TEXT NOT NULL,
            value REAL NOT NULL,
            updated_at TEXT DEFAULT CURRENT_TIMESTAMP,
            PRIMARY KEY (entity_id, feature_name)
        )
    """)
    conn.commit()
    return conn

def store_features(conn, entity_id: str, features: dict):
    """Upsert features for an entity."""
    for name, value in features.items():
        conn.execute(
            """INSERT OR REPLACE INTO features (entity_id, feature_name, value)
               VALUES (?, ?, ?)""",
            (entity_id, name, float(value))
        )
    conn.commit()

def get_features(conn, entity_id: str) -> dict:
    """Retrieve all features for an entity."""
    cursor = conn.execute(
        "SELECT feature_name, value FROM features WHERE entity_id = ?",
        (entity_id,)
    )
    return {row[0]: row[1] for row in cursor.fetchall()}

# Usage
conn = create_feature_store()
store_features(conn, "user_42", {"age": 28, "income": 55000, "credit_score": 720})
store_features(conn, "user_43", {"age": 35, "income": 82000, "credit_score": 780})

print(get_features(conn, "user_42"))
# {'age': 28.0, 'income': 55000.0, 'credit_score': 720.0}
conn.close()
```

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| String formatting SQL queries | Always use `?` or `:name` parameterized placeholders |
| Forgetting `conn.commit()` | Writes are buffered; call `commit()` or use `with` |
| Not closing connections | Use `with sqlite3.connect(...) as conn:` |
| Storing large blobs (model weights) in SQLite | Store the file path in the DB; keep weights on disk |
| Ignoring `row_factory` | Set `conn.row_factory = sqlite3.Row` for dict-like access |
| Not using foreign keys in SQLite | Run `PRAGMA foreign_keys = ON` after connecting |

1. What does the `?` placeholder do in `cursor.execute("SELECT * FROM t WHERE id = ?", (5,))`?
2. Why should you never use f-strings to build SQL queries?
3. How do you read a SQL query result directly into a pandas DataFrame?
4. What is the difference between SQLAlchemy Core and SQLAlchemy ORM?
5. When would you choose SQLite over PostgreSQL for an ML project?

<details>
<summary>Answers</summary>

1. It safely binds the value `5` as a parameter, preventing SQL injection. The database
   engine handles escaping and quoting.
2. F-strings embed user input directly into the SQL string, allowing an attacker to
   inject arbitrary SQL commands (SQL injection).
3. `pd.read_sql_query("SELECT ...", conn)` returns a DataFrame.
4. Core gives you a programmatic way to build SQL expressions. ORM maps Python classes
   to tables and lets you work with objects instead of raw rows.
5. SQLite is ideal for single-user, local projects, prototyping, and experiments that
   do not need concurrent writes. PostgreSQL is better for production services with
   multiple concurrent users, complex queries, and large datasets.

</details>
