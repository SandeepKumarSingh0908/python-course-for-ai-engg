## Section 1: The Basics -- `class`, `__init__`, and `self`

A class is a blueprint; an object is a concrete thing built from that blueprint.

```python
class Model:
    """A minimal ML model wrapper."""

    # Class attribute -- shared by ALL instances
    framework = "custom"

    def __init__(self, name: str, version: int = 1):
        # Instance attributes -- unique to each object
        self.name = name
        self.version = version
        self.is_trained = False

    def summary(self) -> str:
        status = "trained" if self.is_trained else "untrained"
        return f"{self.name} v{self.version} ({status})"
```

### Creating objects

```python
m1 = Model("linear-reg")
m2 = Model("gradient-boost", version=3)

print(m1.summary())  # linear-reg v1 (untrained)
print(m2.summary())  # gradient-boost v3 (untrained)
```

### `self` explained

`self` is just the instance that called the method. Python passes it automatically -- you
never write `m1.summary(m1)`. Inside the method, `self.name` refers to the particular
object's `name`.

### Instance attributes vs class attributes

```python
# Class attribute -- one copy, lives on the class itself
print(Model.framework)          # "custom"
print(m1.framework)             # "custom" (looked up via the class)

# Changing the class attribute affects all instances that haven't overridden it
Model.framework = "sklearn"
print(m2.framework)             # "sklearn"

# Setting on the instance creates a shadow copy for that instance only
m1.framework = "pytorch"
print(m1.framework)             # "pytorch"  (instance attribute)
print(m2.framework)             # "sklearn"  (still class attribute)
```

**Rule of thumb:** Use class attributes for constants or defaults shared across all
instances. Use instance attributes (set in `__init__`) for data that varies per object.

## Section 2: Methods -- Instance, Class, and Static

### Instance methods

The most common kind. They receive `self` and can access/modify instance state.

```python
class Dataset:
    def __init__(self, rows: list[dict]):
        self.rows = rows

    def num_rows(self) -> int:
        """Instance method -- accesses self.rows."""
        return len(self.rows)

    def head(self, n: int = 5) -> list[dict]:
        return self.rows[:n]
```

### Class methods with `@classmethod`

Class methods receive the class (`cls`) instead of an instance. They are commonly used as
**alternate constructors**.

```python
import json

class Dataset:
    def __init__(self, rows: list[dict]):
        self.rows = rows

    @classmethod
    def from_json(cls, path: str) -> "Dataset":
        """Alternate constructor: build a Dataset from a JSON file."""
        with open(path) as f:
            data = json.load(f)
        return cls(data)  # cls(...) calls __init__ on whatever class this is

    @classmethod
    def from_csv_lines(cls, lines: list[str], delimiter: str = ",") -> "Dataset":
        """Another alternate constructor."""
        headers = lines[0].split(delimiter)
        rows = []
        for line in lines[1:]:
            values = line.split(delimiter)
            rows.append(dict(zip(headers, values)))
        return cls(rows)
```

### Static methods with `@staticmethod`

Static methods don't receive `self` or `cls`. They are plain functions that live inside
the class for organizational purposes.

```python
class MathUtils:
    @staticmethod
    def relu(x: float) -> float:
        """Rectified Linear Unit -- common activation function."""
        return max(0.0, x)

    @staticmethod
    def sigmoid(x: float) -> float:
        import math
        return 1.0 / (1.0 + math.exp(-x))

print(MathUtils.relu(-3))    # 0.0
print(MathUtils.sigmoid(0))  # 0.5
```

### When to use which

| Method type   | Receives | Can access instance? | Can access class? | Typical use             |
|---------------|----------|----------------------|-------------------|-------------------------|
| Instance      | `self`   | Yes                  | Yes (via class)   | Most methods            |
| `@classmethod`| `cls`    | No                   | Yes               | Alternate constructors  |
| `@staticmethod`| nothing | No                   | No                | Utility / helper logic  |

## Section 3: Properties with `@property`

Properties let you expose computed values as if they were attributes, and add validation
to setters without changing the caller's code.

```python
class TrainingRun:
    def __init__(self, epochs: int, learning_rate: float):
        self.epochs = epochs
        self._learning_rate = learning_rate  # "private" by convention
        self.history: list[float] = []

    @property
    def learning_rate(self) -> float:
        """Read the learning rate."""
        return self._learning_rate

    @learning_rate.setter
    def learning_rate(self, value: float):
        """Validate before setting."""
        if value <= 0:
            raise ValueError(f"Learning rate must be positive, got {value}")
        if value > 1:
            raise ValueError(f"Learning rate too large: {value}")
        self._learning_rate = value

    @property
    def best_loss(self) -> float | None:
        """Computed property -- no backing attribute."""
        return min(self.history) if self.history else None


run = TrainingRun(epochs=10, learning_rate=0.01)

# Read like an attribute
print(run.learning_rate)   # 0.01

# Set like an attribute -- validation runs automatically
run.learning_rate = 0.001  # OK

try:
    run.learning_rate = -5  # raises ValueError
except ValueError as e:
    print(e)

# Computed property
run.history = [0.9, 0.7, 0.5, 0.4]
print(run.best_loss)       # 0.4
```

### Read-only properties

Omit the setter to make a property read-only:

```python
class Embedding:
    def __init__(self, vector: list[float]):
        self._vector = tuple(vector)  # immutable internal storage

    @property
    def dimension(self) -> int:
        return len(self._vector)

e = Embedding([0.1, 0.2, 0.3])
print(e.dimension)  # 3
# e.dimension = 5   # AttributeError: can't set attribute
```

## Section 4: Putting It Together -- An AI-Flavored Example

```python
class SimpleLinearRegression:
    """Ordinary Least Squares for one feature."""

    algorithm = "OLS"

    def __init__(self):
        self._slope: float | None = None
        self._intercept: float | None = None

    @property
    def is_fitted(self) -> bool:
        return self._slope is not None

    def fit(self, X: list[float], y: list[float]) -> "SimpleLinearRegression":
        n = len(X)
        mean_x = sum(X) / n
        mean_y = sum(y) / n
        numerator = sum((xi - mean_x) * (yi - mean_y) for xi, yi in zip(X, y))
        denominator = sum((xi - mean_x) ** 2 for xi in X)
        self._slope = numerator / denominator
        self._intercept = mean_y - self._slope * mean_x
        return self  # sklearn convention: fit returns self

    def predict(self, X: list[float]) -> list[float]:
        if not self.is_fitted:
            raise RuntimeError("Call fit() before predict()")
        return [self._slope * xi + self._intercept for xi in X]

    @classmethod
    def from_coefficients(cls, slope: float, intercept: float):
        """Create a pre-fitted model."""
        obj = cls()
        obj._slope = slope
        obj._intercept = intercept
        return obj

    def summary(self) -> str:
        if not self.is_fitted:
            return "SimpleLinearRegression (not fitted)"
        return (
            f"SimpleLinearRegression: y = {self._slope:.4f}x + {self._intercept:.4f}"
        )


# Usage
X_train = [1, 2, 3, 4, 5]
y_train = [2.1, 4.0, 5.9, 8.1, 9.8]

model = SimpleLinearRegression()
model.fit(X_train, y_train)
print(model.summary())            # y = 1.9400x + 0.1600
print(model.predict([6, 7, 8]))   # [11.8, 13.74, 15.68]

# Alternate constructor
loaded = SimpleLinearRegression.from_coefficients(2.0, 0.0)
print(loaded.predict([10]))        # [20.0]
```

## Common Mistakes

1. **Forgetting `self`** in the method signature -- Python will pass the instance but your
   method won't have a parameter for it, causing a confusing `TypeError`.

2. **Mutating class attributes by accident** -- `self.some_list.append(x)` on a class-level
   list mutates the shared list. Always initialize mutable attributes in `__init__`.

3. **Using `@staticmethod` when `@classmethod` is needed** -- if you need to call `cls()`
   to construct an instance, you need `@classmethod`.

4. **Naming the backing attribute the same as the property** -- this causes infinite
   recursion. Use `self._name` for storage and `self.name` for the property.

5. **Not returning `self` from `fit()`** -- sklearn convention expects method chaining
   like `model.fit(X, y).predict(X_new)`. Always `return self` from fit-style methods.
