## Section 1: Week 4 Summary

### Day 22 -- File I/O: Text, CSV & JSON

**Core APIs:**
- `open(path, mode, encoding="utf-8")` with `with` statement
- `pathlib.Path` for portable path handling: `/` operator, `.glob()`, `.read_text()`, `.write_text()`
- `csv.reader`, `csv.DictReader`, `csv.writer`, `csv.DictWriter`
- `json.load`/`json.dump` (files), `json.loads`/`json.dumps` (strings)

**Key takeaways:**
- Always use context managers for file operations
- Always specify `encoding="utf-8"` explicitly
- Use `newline=""` when writing CSV files
- Use `pathlib.Path` over string concatenation for paths

### Day 23 -- Exception Handling

**Core APIs:**
- `try` / `except` / `else` / `finally`
- `raise ExceptionType(message)` and `raise ... from ...`
- Custom exception classes inheriting from `Exception`

**Key takeaways:**
- Catch specific exceptions, never bare `except:`
- `else` runs only when no exception occurred; `finally` runs always
- Use `raise ... from e` to preserve the traceback chain
- EAFP (try/except) is preferred over LBYL (if/check) in Python
- Create exception hierarchies for large projects

### Day 24 -- Regular Expressions

**Core APIs:**
- `re.search`, `re.match`, `re.findall`, `re.finditer`, `re.sub`, `re.compile`
- Character classes: `\d`, `\w`, `\s`, `.`
- Quantifiers: `*`, `+`, `?`, `{n,m}`
- Groups: `(...)`, `(?P<name>...)`, `(?:...)`
- Lookahead/lookbehind: `(?=...)`, `(?!...)`, `(?<=...)`, `(?<!...)`

**Key takeaways:**
- Always use raw strings: `r"pattern"`
- `re.match` checks only the start; `re.search` checks anywhere
- Use non-greedy `*?` and `+?` when greedy matching grabs too much
- Compile patterns used in loops for performance
- Prefer simple string methods when regex is overkill

### Day 25 -- Functional Programming

**Core APIs:**
- `lambda`, `map()`, `filter()`, `functools.reduce()`
- `functools.partial`, `functools.lru_cache`
- `itertools.chain`, `itertools.product`, `itertools.combinations`, `itertools.groupby`
- `itertools.islice`, `itertools.takewhile`, `itertools.dropwhile`

**Key takeaways:**
- Prefer list comprehensions over `map`/`filter` with lambdas for simple cases
- `map()` and `filter()` return iterators (one-pass only)
- `itertools.product` is ideal for hyperparameter grid search
- `lru_cache` only works with hashable arguments
- Sort data before using `groupby`

### Day 26 -- Type Hints & Dataclasses

**Core APIs:**
- Type annotations: `int`, `str`, `list[str]`, `dict[str, int]`, `Optional[X]`, `Union[X, Y]`
- `typing.Literal`, `typing.Protocol`, `typing.TypeAlias`, `typing.Callable`
- `@dataclass`, `field()`, `__post_init__`, `asdict()`, `frozen=True`
- Pydantic `BaseModel` for runtime validation

**Key takeaways:**
- Type hints do not enforce types at runtime; use mypy/pyright for checking
- Use `field(default_factory=list)` for mutable defaults in dataclasses
- `__post_init__` is where you validate and compute derived fields
- Use Pydantic at API boundaries; use dataclasses for internal structures

### Day 27 -- Logging, Debugging & Profiling

**Core APIs:**
- `logging.getLogger()`, `logging.basicConfig()`, handlers, formatters
- `breakpoint()` / `pdb.set_trace()`, commands: `n`, `s`, `c`, `p`, `l`, `w`, `q`
- `timeit.timeit()` for micro-benchmarks
- `cProfile.run()` and `pstats.Stats` for full profiling
- `traceback.format_exc()` for capturing tracebacks as strings

**Key takeaways:**
- Use `logging`, not `print()`, in production code
- Use `time.perf_counter()`, not `time.time()`, for timing
- `logger.exception()` automatically includes the traceback
- Set `PYTHONBREAKPOINT=0` to disable breakpoints in production
- `tottime` = time in function only; `cumtime` = time including sub-calls

## Answers to Quick-Fire Questions

1. **Prints `1`.** `int("abc")` raises `ValueError`, so `except` sets `x = 0`, `else` is skipped, `finally` adds 1 making `x = 1`.

2. **`[('a', '1'), ('b', '2'), ('c', '3')]`** -- When the pattern has groups, `findall` returns tuples of group contents.

3. **Mutable default value.** `tags: list[str] = []` shares the same list across all instances. Fix: `tags: list[str] = field(default_factory=list)`.

4. **`[1, "hello", [1]]`** -- `filter(None, ...)` removes falsy values: `0`, `""`, `None`, and `[]` are all falsy.

5. **No handler is configured.** The logger has no handlers, and `basicConfig` was never called. The root logger's default level is `WARNING`, so `INFO` messages are also below the threshold. Fix: call `logging.basicConfig(level=logging.INFO)` or add handlers to the logger.

### Solution 1: Robust Config Loader

```python
import json
import logging
from dataclasses import dataclass
from pathlib import Path

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


class ConfigError(Exception):
    """Raised when config loading or validation fails."""
    pass


@dataclass
class AppConfig:
    model_name: str
    learning_rate: float
    epochs: int
    batch_size: int = 32

    def __post_init__(self):
        if self.learning_rate <= 0:
            raise ConfigError(f"learning_rate must be positive, got {self.learning_rate}")
        if self.epochs < 1:
            raise ConfigError(f"epochs must be >= 1, got {self.epochs}")


def load_config(path: str) -> AppConfig:
    """Load and validate config from a JSON file."""
    try:
        raw = Path(path).read_text(encoding="utf-8")
    except FileNotFoundError as e:
        logger.error("Config file not found: %s", path)
        raise ConfigError(f"Config file not found: {path}") from e

    try:
        data = json.loads(raw)
    except json.JSONDecodeError as e:
        logger.error("Invalid JSON in %s: %s", path, e)
        raise ConfigError(f"Invalid JSON in config file: {path}") from e

    try:
        config = AppConfig(
            model_name=data["model_name"],
            learning_rate=data["learning_rate"],
            epochs=data["epochs"],
            batch_size=data.get("batch_size", 32),
        )
    except KeyError as e:
        logger.error("Missing required key in config: %s", e)
        raise ConfigError(f"Missing required config key: {e}") from e
    except ConfigError:
        logger.error("Config validation failed")
        raise

    logger.info("Config loaded successfully from %s", path)
    return config


# Test
import json
Path("valid_config.json").write_text(
    json.dumps({"model_name": "bert-base", "learning_rate": 0.001, "epochs": 10}),
    encoding="utf-8",
)

config = load_config("valid_config.json")
assert config.model_name == "bert-base"
assert config.learning_rate == 0.001

try:
    load_config("nonexistent.json")
except ConfigError as e:
    print(f"Caught: {e}")

Path("bad.json").write_text("{not valid json", encoding="utf-8")
try:
    load_config("bad.json")
except ConfigError as e:
    print(f"Caught: {e}")

Path("missing_key.json").write_text(json.dumps({"model_name": "bert"}), encoding="utf-8")
try:
    load_config("missing_key.json")
except ConfigError as e:
    print(f"Caught: {e}")

Path("bad_lr.json").write_text(
    json.dumps({"model_name": "bert", "learning_rate": -1, "epochs": 5}),
    encoding="utf-8",
)
try:
    load_config("bad_lr.json")
except ConfigError as e:
    print(f"Caught: {e}")

print("All config loader tests passed!")
```

### Solution 2: Log File Analyzer

```python
import re
from functools import reduce
from itertools import groupby

sample_log = """
2024-03-15 10:00:01 [INFO] Epoch 1/10 loss=2.451 acc=0.321
2024-03-15 10:05:32 [INFO] Epoch 2/10 loss=1.893 acc=0.512
2024-03-15 10:11:05 [WARNING] Gradient norm exceeded threshold: 15.2
2024-03-15 10:11:06 [INFO] Epoch 3/10 loss=1.201 acc=0.689
2024-03-15 10:16:41 [ERROR] NaN loss detected at batch 47
2024-03-15 10:16:42 [INFO] Epoch 4/10 loss=0.892 acc=0.765
2024-03-15 10:22:18 [INFO] Epoch 5/10 loss=0.543 acc=0.840
2024-03-15 10:27:55 [WARNING] Gradient norm exceeded threshold: 12.8
2024-03-15 10:28:00 [INFO] Epoch 6/10 loss=0.321 acc=0.892
"""

# Task 1: Extract all epoch records
epoch_pattern = re.compile(
    r"Epoch (?P<epoch>\d+)/\d+ loss=(?P<loss>\d+\.\d+) acc=(?P<acc>\d+\.\d+)"
)
epoch_records = [
    {"epoch": int(m.group("epoch")), "loss": float(m.group("loss")), "acc": float(m.group("acc"))}
    for m in re.finditer(epoch_pattern, sample_log)
]
print("Epoch records:", epoch_records)

# Task 2: Best epoch (highest accuracy)
best_epoch = max(epoch_records, key=lambda r: r["acc"])
print("Best epoch:", best_epoch)

# Task 3: Average loss using reduce
avg_loss = reduce(lambda acc, r: acc + r["loss"], epoch_records, 0.0) / len(epoch_records)
print(f"Average loss: {avg_loss:.4f}")

# Task 4: WARNING and ERROR messages
warnings_and_errors = re.findall(r"\[(?:WARNING|ERROR)\] (.+)", sample_log)
print("Warnings/Errors:", warnings_and_errors)

# Task 5: Count messages by log level
levels = re.findall(r"\[(INFO|WARNING|ERROR)\]", sample_log)
level_counts = reduce(
    lambda acc, lvl: {**acc, lvl: acc.get(lvl, 0) + 1},
    levels,
    {},
)
print("Level counts:", level_counts)
```

### Solution 3: Typed Data Pipeline

```python
import logging
from dataclasses import dataclass, field
from typing import Callable, Optional

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

TransformFn = Callable[[dict], Optional[dict]]


@dataclass
class PipelineResult:
    records_in: int
    records_out: int
    errors: list[str] = field(default_factory=list)


def run_pipeline(records: list[dict], transforms: list[TransformFn]) -> PipelineResult:
    """Apply a list of transform functions to each record in order."""
    result = PipelineResult(records_in=len(records), records_out=0)

    for record in records:
        current = record
        failed = False
        for transform in transforms:
            try:
                current = transform(current)
                if current is None:
                    break  # filtered out
            except Exception as e:
                logger.warning("Transform error on record %s: %s", record, e)
                result.errors.append(str(e))
                failed = True
                break

        if current is not None and not failed:
            result.records_out += 1

    return result


def normalize_text(record: dict) -> Optional[dict]:
    record = record.copy()
    record["text"] = record["text"].strip().lower()
    if not record["text"]:
        return None
    return record


def validate_score(record: dict) -> Optional[dict]:
    score = record.get("score")
    if not isinstance(score, (int, float)) or score < 0:
        raise ValueError(f"Invalid score: {score}")
    return record


def add_length_feature(record: dict) -> Optional[dict]:
    record = record.copy()
    record["text_length"] = len(record["text"].split())
    return record


test_data = [
    {"text": "  Great product!  ", "score": 5},
    {"text": "", "score": 3},
    {"text": "Terrible", "score": -1},
    {"text": "  Okay experience  ", "score": 3},
]

result = run_pipeline(test_data, [normalize_text, validate_score, add_length_feature])
print(result)
assert result.records_in == 4
assert result.records_out == 2
assert len(result.errors) == 1
print("Typed pipeline test passed!")
```
