## Section 1: Text Files and Context Managers

### The `open()` Built-in

`open()` returns a file object. The two arguments you will use most often are the file path and the mode.

| Mode | Meaning |
|------|---------|
| `"r"` | Read (default) |
| `"w"` | Write (truncates existing content) |
| `"a"` | Append |
| `"x"` | Exclusive create (fails if file exists) |
| `"b"` | Binary mode (combine: `"rb"`, `"wb"`) |

### Context Managers: the `with` Statement

Always open files inside a `with` block. The file is guaranteed to close when the block exits, even if an exception is raised.

```python
# Writing text
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("First line\n")
    f.write("Second line\n")

# Reading text
with open("notes.txt", "r", encoding="utf-8") as f:
    content = f.read()        # entire file as one string
    print(content)
```

### Reading Strategies

```python
with open("notes.txt", encoding="utf-8") as f:
    # Option 1: read everything at once (fine for small files)
    text = f.read()

with open("notes.txt", encoding="utf-8") as f:
    # Option 2: read line by line (memory-efficient for large files)
    for line in f:
        print(line.strip())

with open("notes.txt", encoding="utf-8") as f:
    # Option 3: read all lines into a list
    lines = f.readlines()
```

For large dataset files (multiple GB), always iterate line by line. Loading the entire file into memory with `.read()` will crash your process.

## Section 2: Modern Path Handling with `pathlib`

The `pathlib` module replaces the older `os.path` functions with an object-oriented interface.

```python
from pathlib import Path

# Build paths portably (works on Windows, macOS, Linux)
data_dir = Path("data")
csv_path = data_dir / "training" / "dataset.csv"
print(csv_path)  # data/training/dataset.csv

# Useful properties
print(csv_path.name)      # dataset.csv
print(csv_path.stem)      # dataset
print(csv_path.suffix)    # .csv
print(csv_path.parent)    # data/training

# Check existence
if csv_path.exists():
    print("File found")

# Create directories (including parents)
output_dir = Path("output") / "models"
output_dir.mkdir(parents=True, exist_ok=True)

# Glob for files
for json_file in Path("configs").glob("*.json"):
    print(json_file)

# Read/write shortcuts (Python 3.5+)
text = Path("notes.txt").read_text(encoding="utf-8")
Path("copy.txt").write_text(text, encoding="utf-8")
```

Prefer `pathlib.Path` over string concatenation or `os.path.join` in all new code. It is clearer, safer, and more expressive.

## Section 3: CSV Files

The `csv` module handles the quoting, escaping, and delimiter rules that make hand-parsing CSV fragile.

### Reading CSV

```python
import csv

# Basic reader: each row is a list of strings
with open("scores.csv", encoding="utf-8") as f:
    reader = csv.reader(f)
    header = next(reader)           # ['name', 'score', 'grade']
    for row in reader:
        name, score, grade = row
        print(f"{name}: {score}")
```

### DictReader: Rows as Dictionaries

```python
with open("scores.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)      # uses first row as keys
    for row in reader:
        print(row["name"], row["score"])
```

### Writing CSV

```python
rows = [
    {"name": "Alice", "score": 95, "grade": "A"},
    {"name": "Bob", "score": 82, "grade": "B"},
]

with open("output.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "score", "grade"])
    writer.writeheader()
    writer.writerows(rows)
```

The `newline=""` argument prevents double-spaced rows on Windows. Always include it when writing CSV.

## Section 4: JSON Files

JSON is the lingua franca of web APIs and configuration files. Python's `json` module provides four core functions.

| Function | Input | Output |
|----------|-------|--------|
| `json.loads(s)` | JSON string | Python object |
| `json.dumps(obj)` | Python object | JSON string |
| `json.load(f)` | File object | Python object |
| `json.dump(obj, f)` | Python object | Writes to file |

```python
import json

# --- Strings ---
data = {"model": "gpt-4", "temperature": 0.7, "max_tokens": 512}
json_str = json.dumps(data, indent=2)
print(json_str)

parsed = json.loads(json_str)
print(parsed["model"])  # gpt-4

# --- Files ---
with open("config.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2)

with open("config.json", encoding="utf-8") as f:
    config = json.load(f)
    print(config["temperature"])  # 0.7
```

### Handling Non-Serializable Types

`json.dump` only supports `dict`, `list`, `str`, `int`, `float`, `bool`, and `None`. For other types, supply a `default` function.

```python
from datetime import datetime

def default_serializer(obj):
    if isinstance(obj, datetime):
        return obj.isoformat()
    raise TypeError(f"Object of type {type(obj)} is not JSON serializable")

record = {"event": "training_start", "timestamp": datetime.now()}
print(json.dumps(record, default=default_serializer, indent=2))
```

## Section 5: Encoding

Text files are sequences of bytes interpreted through an encoding. UTF-8 covers virtually all human languages and is the default you should always specify explicitly.

```python
# Specify encoding explicitly -- never rely on the platform default
with open("data.txt", encoding="utf-8") as f:
    text = f.read()
```

### Handling UnicodeDecodeError

Real-world data is messy. Some files claim to be UTF-8 but contain Latin-1 or Windows-1252 bytes.

```python
# Strategy 1: try utf-8, fall back to latin-1
try:
    text = Path("messy.txt").read_text(encoding="utf-8")
except UnicodeDecodeError:
    text = Path("messy.txt").read_text(encoding="latin-1")

# Strategy 2: replace or ignore bad bytes
with open("messy.txt", encoding="utf-8", errors="replace") as f:
    text = f.read()  # bad bytes become U+FFFD replacement characters

# Strategy 3: use the chardet library to detect encoding
# pip install chardet
import chardet

raw = Path("messy.txt").read_bytes()
detected = chardet.detect(raw)
print(detected)  # {'encoding': 'Windows-1252', 'confidence': 0.73, ...}
text = raw.decode(detected["encoding"])
```

## Section 6: Worked Example -- Loading and Transforming a Dataset

Imagine you receive a CSV of labeled training examples and need to convert it to JSON Lines format (one JSON object per line), which many ML frameworks expect.

```python
import csv
import json
from pathlib import Path

def csv_to_jsonl(csv_path: str, jsonl_path: str) -> int:
    """Convert a CSV file to JSON Lines format.

    Returns the number of records written.
    """
    csv_file = Path(csv_path)
    if not csv_file.exists():
        raise FileNotFoundError(f"Input file not found: {csv_path}")

    count = 0
    with open(csv_path, encoding="utf-8") as fin, \
         open(jsonl_path, "w", encoding="utf-8") as fout:

        reader = csv.DictReader(fin)
        for row in reader:
            # Convert numeric fields
            if "score" in row:
                row["score"] = float(row["score"])
            json_line = json.dumps(row, ensure_ascii=False)
            fout.write(json_line + "\n")
            count += 1

    return count

# Usage
written = csv_to_jsonl("training_data.csv", "training_data.jsonl")
print(f"Converted {written} records")
```

Key details: we open both files in a single `with` statement, use `DictReader` so each row is already keyed by the header, and convert numeric strings to floats before serializing.

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Forgetting `encoding="utf-8"` | Always pass it explicitly; the platform default varies |
| Opening files without `with` | Always use a context manager to ensure the file closes |
| Missing `newline=""` when writing CSV | Add it to prevent blank rows on Windows |
| Using `json.loads` on a file object | `loads` takes a string; use `json.load` (no "s") for file objects |
| Building paths with string concatenation | Use `pathlib.Path` or `os.path.join` |
| Reading a huge file with `.read()` | Iterate line by line for large files |
