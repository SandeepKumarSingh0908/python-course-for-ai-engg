## Section 1: Basic Type Annotations

Type hints were introduced in Python 3.5 (PEP 484). They do not affect runtime behavior -- Python does not enforce them. They are used by static analysis tools (mypy, pyright) and IDEs.

```python
# Variable annotations
name: str = "bert-base"
learning_rate: float = 0.001
epochs: int = 10
is_training: bool = True

# Function annotations
def compute_loss(predictions: list[float], targets: list[float]) -> float:
    """Compute mean squared error."""
    n = len(predictions)
    return sum((p - t) ** 2 for p, t in zip(predictions, targets)) / n
```

### Built-in Generic Types (Python 3.9+)

Since Python 3.9, you can use built-in types directly as generics.

```python
# Python 3.9+ style (preferred)
def process_batch(texts: list[str], max_len: int = 512) -> dict[str, list[int]]:
    ...

# Python 3.7-3.8 style (import from typing)
from typing import List, Dict
def process_batch(texts: List[str], max_len: int = 512) -> Dict[str, List[int]]:
    ...
```

### Common Type Patterns

```python
from typing import Optional, Union

# Optional: the value might be None
def find_model(name: str) -> Optional[dict]:
    """Returns model config or None if not found."""
    models = {"bert": {"layers": 12}, "gpt2": {"layers": 24}}
    return models.get(name)  # returns None if missing

# Union: accepts multiple types
def normalize(data: Union[list, tuple]) -> list:
    return list(data)

# Python 3.10+ shorthand for Union
def normalize(data: list | tuple) -> list:
    return list(data)

# None return
def log_event(message: str) -> None:
    print(f"[LOG] {message}")
```

## Section 2: Advanced typing Module Features

### Literal -- Restrict to Specific Values

```python
from typing import Literal

def set_mode(mode: Literal["train", "eval", "predict"]) -> None:
    print(f"Mode set to: {mode}")

set_mode("train")    # OK
set_mode("test")     # mypy error: not a valid literal
```

### TypeAlias -- Named Type Shortcuts

```python
from typing import TypeAlias

# Define once, reuse everywhere
Embedding: TypeAlias = list[float]
BatchEmbeddings: TypeAlias = list[Embedding]
TokenMap: TypeAlias = dict[str, int]

def encode(texts: list[str]) -> BatchEmbeddings:
    return [[0.1, 0.2, 0.3] for _ in texts]
```

### Callable -- Type for Functions

```python
from typing import Callable

# A function that takes two floats and returns a float
LossFunction = Callable[[list[float], list[float]], float]

def train(
    data: list[dict],
    loss_fn: LossFunction,
    epochs: int = 10,
) -> float:
    """Train with a pluggable loss function."""
    # ... training logic
    return 0.05  # final loss
```

### Protocol -- Structural Subtyping (Duck Typing with Types)

```python
from typing import Protocol

class Predictable(Protocol):
    def predict(self, inputs: list[str]) -> list[float]:
        ...

def evaluate(model: Predictable, test_data: list[str]) -> float:
    """Works with ANY object that has a .predict() method."""
    predictions = model.predict(test_data)
    return sum(predictions) / len(predictions)

# No inheritance required -- just implement the method
class MyModel:
    def predict(self, inputs: list[str]) -> list[float]:
        return [0.9] * len(inputs)

evaluate(MyModel(), ["test"])  # Works! MyModel satisfies Predictable
```

### TypedDict -- Typed Dictionaries

```python
from typing import TypedDict

class ModelConfig(TypedDict):
    name: str
    layers: int
    hidden_size: int
    dropout: float

def load_model(config: ModelConfig) -> None:
    print(f"Loading {config['name']} with {config['layers']} layers")

# mypy checks that the dict has the right keys and types
config: ModelConfig = {
    "name": "transformer",
    "layers": 6,
    "hidden_size": 512,
    "dropout": 0.1,
}
```

## Section 3: Dataclasses

Dataclasses eliminate the boilerplate of writing `__init__`, `__repr__`, `__eq__`, and other dunder methods for classes that primarily hold data.

### Basic Usage

```python
from dataclasses import dataclass

@dataclass
class TrainingConfig:
    model_name: str
    learning_rate: float
    epochs: int
    batch_size: int
    dropout: float = 0.1       # default value
    device: str = "cpu"        # default value

# Auto-generated __init__
config = TrainingConfig(
    model_name="bert-base",
    learning_rate=0.001,
    epochs=10,
    batch_size=32,
)

# Auto-generated __repr__
print(config)
# TrainingConfig(model_name='bert-base', learning_rate=0.001, epochs=10,
#                batch_size=32, dropout=0.1, device='cpu')

# Auto-generated __eq__
config2 = TrainingConfig("bert-base", 0.001, 10, 32)
print(config == config2)  # True

# Attribute access (not dict-style)
print(config.learning_rate)  # 0.001
```

### The field() Function and Mutable Defaults

```python
from dataclasses import dataclass, field

@dataclass
class Experiment:
    name: str
    tags: list[str] = field(default_factory=list)    # mutable default
    metrics: dict[str, float] = field(default_factory=dict)
    _internal_id: int = field(default=0, repr=False)  # hidden from repr

exp = Experiment("exp-001")
exp.tags.append("baseline")
exp.metrics["accuracy"] = 0.92
print(exp)  # Experiment(name='exp-001', tags=['baseline'], metrics={'accuracy': 0.92})
```

**Never use a mutable default directly** (e.g., `tags: list = []`). It creates a shared list across all instances. Always use `field(default_factory=list)`.

### __post_init__ -- Validation and Derived Fields

```python
@dataclass
class DataSplit:
    total_samples: int
    train_ratio: float = 0.8
    val_ratio: float = 0.1
    test_ratio: float = 0.1
    # Derived fields (computed, not passed in)
    train_size: int = field(init=False)
    val_size: int = field(init=False)
    test_size: int = field(init=False)

    def __post_init__(self):
        # Validation
        total_ratio = self.train_ratio + self.val_ratio + self.test_ratio
        if abs(total_ratio - 1.0) > 1e-6:
            raise ValueError(f"Ratios must sum to 1.0, got {total_ratio}")
        if self.total_samples <= 0:
            raise ValueError("total_samples must be positive")

        # Compute derived fields
        self.train_size = int(self.total_samples * self.train_ratio)
        self.val_size = int(self.total_samples * self.val_ratio)
        self.test_size = self.total_samples - self.train_size - self.val_size

split = DataSplit(total_samples=1000)
print(split.train_size)  # 800
print(split.val_size)    # 100
print(split.test_size)   # 100
```

### Frozen Dataclasses (Immutable)

```python
@dataclass(frozen=True)
class ModelCheckpoint:
    path: str
    epoch: int
    val_loss: float

ckpt = ModelCheckpoint("/models/best.pt", epoch=7, val_loss=0.342)
# ckpt.epoch = 8  # raises FrozenInstanceError
```

### Converting Dataclasses to Dicts

```python
from dataclasses import asdict, astuple

config = TrainingConfig("bert", 0.001, 10, 32)
config_dict = asdict(config)
print(config_dict)
# {'model_name': 'bert', 'learning_rate': 0.001, 'epochs': 10,
#  'batch_size': 32, 'dropout': 0.1, 'device': 'cpu'}

# Useful for JSON serialization
import json
print(json.dumps(asdict(config), indent=2))
```

## Section 4: Brief Pydantic Introduction

While dataclasses provide structure, they do not validate data at runtime. Pydantic does.

```python
# pip install pydantic
from pydantic import BaseModel, Field, field_validator

class TrainingRequest(BaseModel):
    model_name: str = Field(..., min_length=1, description="Name of the model")
    learning_rate: float = Field(0.001, gt=0, lt=1)
    epochs: int = Field(10, ge=1, le=1000)
    batch_size: int = Field(32, ge=1)
    temperature: float = Field(0.7, ge=0.0, le=2.0)

    @field_validator("model_name")
    @classmethod
    def model_must_be_known(cls, v: str) -> str:
        known = {"bert-base", "bert-large", "gpt2", "gpt2-medium"}
        if v not in known:
            raise ValueError(f"Unknown model: {v}. Choose from {known}")
        return v

# Valid input
req = TrainingRequest(model_name="bert-base", epochs=20)
print(req.model_dump())  # dict output

# Invalid input -- raises ValidationError with clear messages
try:
    bad = TrainingRequest(model_name="", learning_rate=-0.1)
except Exception as e:
    print(e)
```

### When to Use What

| Tool | Use When |
|------|----------|
| Plain `dict` | Quick scripts, prototyping |
| `dataclass` | Internal data structures, configs within your codebase |
| `Pydantic` | API boundaries, user input, external config files, anything that needs runtime validation |
| `TypedDict` | Typing existing dict-based code without refactoring |

## Section 5: Worked Example -- ML Experiment Configuration System

```python
from dataclasses import dataclass, field, asdict
from typing import Optional
import json
from pathlib import Path

@dataclass
class OptimizerConfig:
    name: str = "adam"
    learning_rate: float = 0.001
    weight_decay: float = 0.0
    betas: tuple[float, float] = (0.9, 0.999)

@dataclass
class DataConfig:
    train_path: str = "data/train.csv"
    val_path: str = "data/val.csv"
    max_seq_length: int = 512
    num_workers: int = 4

@dataclass
class ExperimentConfig:
    """Top-level experiment configuration."""
    name: str
    model_name: str
    epochs: int = 10
    batch_size: int = 32
    seed: int = 42
    optimizer: OptimizerConfig = field(default_factory=OptimizerConfig)
    data: DataConfig = field(default_factory=DataConfig)
    tags: list[str] = field(default_factory=list)
    notes: Optional[str] = None

    def save(self, path: str) -> None:
        """Save config to JSON."""
        # asdict handles nested dataclasses automatically
        config_dict = asdict(self)
        # Convert tuple to list for JSON compatibility
        config_dict["optimizer"]["betas"] = list(
            config_dict["optimizer"]["betas"]
        )
        Path(path).write_text(
            json.dumps(config_dict, indent=2), encoding="utf-8"
        )

    @classmethod
    def load(cls, path: str) -> "ExperimentConfig":
        """Load config from JSON."""
        raw = json.loads(Path(path).read_text(encoding="utf-8"))
        # Reconstruct nested dataclasses
        raw["optimizer"] = OptimizerConfig(**raw["optimizer"])
        raw["data"] = DataConfig(**raw["data"])
        return cls(**raw)

# Usage
config = ExperimentConfig(
    name="baseline-bert",
    model_name="bert-base",
    epochs=20,
    optimizer=OptimizerConfig(learning_rate=0.0005),
    tags=["baseline", "bert"],
    notes="First experiment with BERT on our dataset",
)

config.save("experiment.json")
loaded = ExperimentConfig.load("experiment.json")
print(loaded.optimizer.learning_rate)  # 0.0005
print(loaded.tags)                     # ['baseline', 'bert']
```

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Using mutable default in dataclass | Use `field(default_factory=list)` instead of `= []` |
| Thinking type hints enforce types at runtime | They are only checked by mypy/pyright; use Pydantic for runtime validation |
| Importing from `typing` unnecessarily on 3.10+ | Use `list[str]` and `str \| None` directly |
| Forgetting `@classmethod` on Pydantic validators | Pydantic v2 requires `@classmethod` on `@field_validator` |
| Deeply nesting dataclasses without serialization helpers | Add `to_dict()` / `from_dict()` methods for JSON round-tripping |
| Using `Optional[X]` without understanding it means `X \| None` | `Optional[int]` allows `None`; if a value is truly required, do not use `Optional` |
