## Section 1: Arithmetic Operators

```python
a, b = 17, 5

print(a + b)    # 22   Addition
print(a - b)    # 12   Subtraction
print(a * b)    # 85   Multiplication
print(a / b)    # 3.4  True division (always returns float)
print(a // b)   # 3    Floor division (rounds toward negative infinity)
print(a % b)    # 2    Modulo (remainder)
print(a ** b)   # 1419857  Exponentiation (17^5)
```

### Floor division nuances

```python
print(7 // 2)       # 3
print(-7 // 2)      # -4  (floors toward negative infinity, not toward zero)
print(7.0 // 2)     # 3.0 (returns float if either operand is float)
```

### Modulo with negative numbers

```python
print(7 % 3)        # 1
print(-7 % 3)       # 2   (result always has the sign of the divisor)
```

### Division by zero

```python
# 10 / 0    -> ZeroDivisionError
# 10 // 0   -> ZeroDivisionError
# 10 % 0    -> ZeroDivisionError
```

## Section 2: Comparison Operators

Comparison operators return `True` or `False`.

```python
x, y = 10, 20

print(x == y)    # False   Equal
print(x != y)    # True    Not equal
print(x < y)     # True    Less than
print(x > y)     # False   Greater than
print(x <= y)    # True    Less than or equal
print(x >= y)    # False   Greater than or equal
```

### Chained comparisons

Python supports chained comparisons -- a feature many languages lack.

```python
score = 75
print(60 <= score <= 100)   # True  -- equivalent to (60 <= score) and (score <= 100)

# Useful for range checks in data validation
temperature = 98.6
print(97.0 <= temperature <= 99.5)  # True -- normal range
```

### Identity vs. equality

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)    # True  -- same value
print(a is b)    # False -- different objects in memory
print(a is c)    # True  -- same object
```

Use `==` for value comparison. Use `is` only for `None`, `True`, `False`, or when you intentionally need identity checks.

## Section 3: Logical Operators

```python
print(True and False)    # False
print(True or False)     # True
print(not True)          # False
```

### Short-circuit evaluation

Python stops evaluating as soon as the result is determined.

```python
# 'and' returns the first falsy value, or the last value if all truthy
print(1 and 2 and 3)      # 3
print(1 and 0 and 3)      # 0

# 'or' returns the first truthy value, or the last value if all falsy
print(0 or "" or "hello") # "hello"
print(0 or "" or None)    # None
```

### Practical pattern: default values

```python
user_name = None
display_name = user_name or "Anonymous"
print(display_name)  # "Anonymous"

# Caution: this treats 0 and "" as missing too.
# For precise None-checks, use: value if value is not None else default
```

## Section 4: Bitwise Operators

You will not use these daily, but they appear in specific contexts: feature hashing, binary flags, and low-level data manipulation.

```python
a, b = 0b1100, 0b1010   # 12, 10

print(bin(a & b))    # 0b1000  (AND)
print(bin(a | b))    # 0b1110  (OR)
print(bin(a ^ b))    # 0b0110  (XOR)
print(bin(~a))       # -0b1101 (NOT -- inverts all bits)
print(bin(a << 2))   # 0b110000 (left shift -- multiply by 4)
print(bin(a >> 2))   # 0b11     (right shift -- divide by 4)
```

### Where you will see bitwise operators in AI work

- **pandas**: `df[(df["age"] > 30) & (df["score"] > 0.8)]` -- uses `&` and `|` instead of `and`/`or` for element-wise operations on arrays.
- **NumPy boolean indexing**: same pattern.
- **Hash functions and random seeds**: bit manipulation for reproducibility.

## Section 5: Assignment Operators

Assignment operators combine an operation with assignment.

```python
x = 10
x += 5     # x = x + 5   -> 15
x -= 3     # x = x - 3   -> 12
x *= 2     # x = x * 2   -> 24
x /= 4     # x = x / 4   -> 6.0
x //= 2    # x = x // 2  -> 3.0
x %= 2     # x = x % 2   -> 1.0
x **= 3    # x = x ** 3  -> 1.0
```

### Walrus operator `:=` (Python 3.8+)

The walrus operator assigns a value inside an expression.

```python
# Without walrus
line = input("Enter text: ")
while line != "quit":
    print(f"You said: {line}")
    line = input("Enter text: ")

# With walrus -- avoids duplicating the input() call
while (line := input("Enter text: ")) != "quit":
    print(f"You said: {line}")
```

## Section 6: Operator Precedence

From highest to lowest (simplified):

| Precedence | Operators                          |
|:----------:|:-----------------------------------|
| 1          | `**`                               |
| 2          | `~`, unary `+`, unary `-`         |
| 3          | `*`, `/`, `//`, `%`               |
| 4          | `+`, `-`                          |
| 5          | `<<`, `>>`                        |
| 6          | `&`                               |
| 7          | `^`                               |
| 8          | `\|`                              |
| 9          | `==`, `!=`, `<`, `>`, `<=`, `>=`, `is`, `in` |
| 10         | `not`                             |
| 11         | `and`                             |
| 12         | `or`                              |

**Golden rule:** When in doubt, use parentheses. Readability beats cleverness.

```python
# Confusing
result = 2 + 3 * 4 ** 2 / 8

# Clear
result = 2 + ((3 * (4 ** 2)) / 8)   # 2 + (3 * 16 / 8) = 2 + 6.0 = 8.0
```

## Section 7: Worked Example -- Feature Scaling

A common ML preprocessing step is min-max normalization:

```
normalized = (value - min) / (max - min)
```

```python
# Raw feature values
temperatures = [68, 72, 55, 89, 95, 60, 77]

min_temp = min(temperatures)  # 55
max_temp = max(temperatures)  # 95
range_temp = max_temp - min_temp  # 40

normalized = []
for temp in temperatures:
    norm = (temp - min_temp) / range_temp
    norm = round(norm, 4)
    normalized.append(norm)

print(normalized)
# [0.325, 0.425, 0.0, 0.85, 1.0, 0.125, 0.55]

# Verify: min should be 0.0, max should be 1.0
print(f"Range check: min={min(normalized)}, max={max(normalized)}")
```

This example uses arithmetic operators (`-`, `/`), comparison (implicit in `min`/`max`), and assignment (`=`, `+=` if we had used it).

## Common Mistakes

- **Using `and`/`or` instead of `&`/`|` in pandas/NumPy.** Element-wise boolean operations on arrays require bitwise operators, not logical ones. `df[condition1 & condition2]` is correct; `df[condition1 and condition2]` raises an error.
- **Forgetting that `/` always returns a float.** `10 / 2` returns `5.0`, not `5`. Use `//` if you need an integer result.
- **Right-associativity of `**`.** `2 ** 3 ** 2` is `2 ** 9 = 512`, not `8 ** 2 = 64`.
- **Relying on `or` for defaults when `0` is a valid value.** `count = user_count or 10` will replace `0` with `10`, which may not be intended.
