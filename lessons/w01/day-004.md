## Section 1: for Loops

The `for` loop iterates over any **iterable** -- lists, tuples, strings, dictionaries, files, ranges, generators, and more.

```python
# Iterating over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)
```

### range()

`range()` generates a sequence of integers. It is lazy -- it does not create a list in memory.

```python
# range(stop) -- 0 to stop-1
for i in range(5):
    print(i)    # 0, 1, 2, 3, 4

# range(start, stop) -- start to stop-1
for i in range(2, 6):
    print(i)    # 2, 3, 4, 5

# range(start, stop, step)
for i in range(0, 10, 2):
    print(i)    # 0, 2, 4, 6, 8

# Counting backwards
for i in range(5, 0, -1):
    print(i)    # 5, 4, 3, 2, 1
```

### enumerate() -- get index and value

Never manually track an index counter. Use `enumerate()`.

```python
classes = ["cat", "dog", "bird", "fish"]

# Anti-pattern
i = 0
for cls in classes:
    print(f"{i}: {cls}")
    i += 1

# Pythonic
for i, cls in enumerate(classes):
    print(f"{i}: {cls}")

# Start from a different index
for i, cls in enumerate(classes, start=1):
    print(f"{i}: {cls}")   # 1: cat, 2: dog, ...
```

### zip() -- iterate over multiple sequences in parallel

```python
names = ["Alice", "Bob", "Charlie"]
scores = [92, 85, 78]
grades = ["A", "B", "C+"]

for name, score, grade in zip(names, scores, grades):
    print(f"{name}: {score} ({grade})")

# Alice: 92 (A)
# Bob: 85 (B)
# Charlie: 78 (C+)
```

`zip()` stops at the **shortest** iterable. Use `itertools.zip_longest` if you need to continue to the longest.

```python
from itertools import zip_longest

a = [1, 2, 3]
b = [10, 20]

for x, y in zip_longest(a, b, fillvalue=0):
    print(x, y)
# 1 10
# 2 20
# 3 0
```

### Iterating over dictionaries

```python
hyperparams = {"learning_rate": 0.001, "batch_size": 32, "epochs": 10}

# Keys (default)
for key in hyperparams:
    print(key)

# Values
for value in hyperparams.values():
    print(value)

# Key-value pairs
for key, value in hyperparams.items():
    print(f"{key}: {value}")
```

## Section 2: while Loops

`while` loops repeat as long as a condition is `True`. Use them when you do not know the number of iterations in advance.

```python
# Countdown
count = 5
while count > 0:
    print(count)
    count -= 1
print("Liftoff!")
```

### Practical example: convergence check

In ML, you often train until a loss value converges.

```python
import random

loss = 10.0
epoch = 0
threshold = 0.01

while loss > threshold:
    # Simulate training (loss decreases with some noise)
    loss *= random.uniform(0.7, 0.95)
    epoch += 1
    print(f"Epoch {epoch}: loss = {loss:.4f}")

print(f"Converged after {epoch} epochs")
```

### Infinite loops with explicit break

```python
while True:
    user_input = input("Enter a number (or 'quit'): ")
    if user_input == "quit":
        break
    try:
        number = float(user_input)
        print(f"Square: {number ** 2}")
    except ValueError:
        print("Invalid input, try again")
```

### Avoid infinite loops

Always ensure your while loop has a path to termination. A common safeguard is a maximum iteration count.

```python
max_iterations = 1000
iteration = 0

while some_condition and iteration < max_iterations:
    # do work
    iteration += 1

if iteration == max_iterations:
    print("Warning: reached max iterations without converging")
```

## Section 3: break, continue, and the else Clause

### break -- exit the loop immediately

```python
# Find the first negative number
data = [4, 7, 2, -3, 8, -1]

for value in data:
    if value < 0:
        print(f"First negative: {value}")
        break
# Output: First negative: -3
```

### continue -- skip to the next iteration

```python
# Process only valid values
data = [10, None, 25, None, 30, None]

total = 0
count = 0
for value in data:
    if value is None:
        continue
    total += value
    count += 1

print(f"Average of valid values: {total / count}")   # 21.666...
```

### else clause on loops

The `else` block runs only if the loop completed **without** hitting a `break`. This is unusual in most languages.

```python
# Search for a value
target = 42
numbers = [10, 20, 30, 40, 50]

for num in numbers:
    if num == target:
        print(f"Found {target}!")
        break
else:
    print(f"{target} not found in the list")

# Output: 42 not found in the list
```

This is cleaner than using a `found` flag variable.

## Section 4: Nested Loops

Sometimes you need a loop inside a loop -- for example, comparing every pair of items.

```python
# Generate all pairs of features for interaction terms
features = ["age", "income", "score"]

pairs = []
for i in range(len(features)):
    for j in range(i + 1, len(features)):
        pair = (features[i], features[j])
        pairs.append(pair)
        print(f"Interaction: {pair[0]} x {pair[1]}")

# Interaction: age x income
# Interaction: age x score
# Interaction: income x score
```

### When to avoid nested loops

Nested loops have O(n^2) time complexity (or worse). For large datasets, this becomes a bottleneck.

```python
# BAD: O(n^2) -- checking for duplicates
data = list(range(10000))
duplicates = []
for i in range(len(data)):
    for j in range(i + 1, len(data)):
        if data[i] == data[j]:
            duplicates.append(data[i])

# GOOD: O(n) -- use a set
seen = set()
duplicates = []
for item in data:
    if item in seen:
        duplicates.append(item)
    seen.add(item)
```

**Rule of thumb:** If you find yourself writing nested loops over large data, stop and ask whether a set, dictionary, or library function (NumPy, pandas) can do it in O(n) or O(1).

## Section 5: Worked Example -- Mini Batch Processor

Simulate splitting data into batches for model training.

```python
def create_batches(data, batch_size):
    """Split data into batches of a given size.
    
    The last batch may be smaller than batch_size.
    """
    batches = []
    for start in range(0, len(data), batch_size):
        batch = data[start:start + batch_size]
        batches.append(batch)
    return batches


def simulate_training(data, batch_size=4, epochs=3):
    """Simulate a training loop over multiple epochs."""
    for epoch in range(1, epochs + 1):
        print(f"\n--- Epoch {epoch} ---")
        batches = create_batches(data, batch_size)
        epoch_loss = 0.0

        for batch_idx, batch in enumerate(batches):
            # Simulate a batch loss (decreases with epoch)
            batch_loss = sum(batch) / len(batch) / epoch
            epoch_loss += batch_loss
            print(f"  Batch {batch_idx}: items={batch}, loss={batch_loss:.2f}")

        avg_loss = epoch_loss / len(batches)
        print(f"  Epoch {epoch} avg loss: {avg_loss:.2f}")


# Sample data (imagine these are feature magnitudes)
sample_data = [10, 23, 5, 17, 8, 31, 14, 2, 19, 27]
simulate_training(sample_data, batch_size=3, epochs=3)
```

This example demonstrates `for` with `range()`, `enumerate()`, nested loops (epochs and batches), and the kind of iteration patterns you will see in real training code.

## Common Mistakes

- **Modifying a list while iterating over it.** This leads to skipped elements or infinite loops. Iterate over a copy or build a new list instead.
  ```python
  # BAD
  for item in items:
      if item < 0:
          items.remove(item)   # Skips elements!
  
  # GOOD
  items = [item for item in items if item >= 0]
  ```
- **Using `range(len(...))` when `enumerate()` would be cleaner.** If you need both index and value, use `enumerate()`.
- **Off-by-one errors with `range()`.** Remember that `range(n)` goes from 0 to n-1, and `range(a, b)` excludes `b`.
- **Forgetting to update the loop variable in `while`.** This creates an infinite loop.
- **Nested loops where vectorized operations would work.** In real ML code, prefer NumPy/pandas vectorized operations over Python loops for large data.

### Solution 3: Find convergence

```python
value = 100.0
step = 0
max_steps = 100

while value >= 1.0 and step < max_steps:
    value *= 0.85
    step += 1
    print(f"Step {step}: {value:.4f}")
else:
    if step == max_steps and value >= 1.0:
        print("Did not converge within 100 steps.")
    else:
        print(f"Dropped below 1.0 at step {step} (value = {value:.4f})")
```

### Solution 4: Pair-wise distance

```python
points_a = [(0, 0), (1, 1), (2, 2)]
points_b = [(3, 3), (4, 4)]

for x1, y1 in points_a:
    for x2, y2 in points_b:
        distance = ((x1 - x2) ** 2 + (y1 - y2) ** 2) ** 0.5
        print(f"({x1},{y1}) -> ({x2},{y2})  distance: {distance:.4f}")
```

### Solution 5: Transpose a matrix

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]

# Loop-based transpose
rows = len(matrix)
cols = len(matrix[0])
transposed = []

for c in range(cols):
    new_row = []
    for r in range(rows):
        new_row.append(matrix[r][c])
    transposed.append(new_row)

print("Loop-based transpose:")
for row in transposed:
    print(row)

# One-liner using zip
transposed_zip = list(zip(*matrix))
print("\nzip(*matrix) transpose:")
for row in transposed_zip:
    print(row)
```
