## Section 1: String Basics

Strings are **immutable** sequences of Unicode characters. Every string method returns a new string; the original is never modified.

```python
s = "Hello, World!"
print(len(s))          # 13
print(s[0])            # H
print(s[-1])           # !
print(type(s))         # <class 'str'>
```

### Creating strings

```python
single = 'single quotes'
double = "double quotes"
triple_single = '''triple single
spans multiple lines'''
triple_double = """triple double
also spans multiple lines"""

# Escape characters
newline = "first line\nsecond line"
tab = "col1\tcol2"
backslash = "path\\to\\file"
quote = "she said \"hello\""
```

## Section 2: String Formatting

### f-strings (Python 3.6+) -- the preferred way

```python
name = "Alice"
accuracy = 0.9567
epoch = 42

print(f"Name: {name}")
print(f"Accuracy: {accuracy:.2%}")        # Accuracy: 95.67%
print(f"Epoch: {epoch:04d}")              # Epoch: 0042
print(f"Loss: {0.00345:.2e}")             # Loss: 3.45e-03
print(f"{'centered':^20}")                # '      centered      '
print(f"{'left':<20}|")                   # 'left                |'
print(f"{'right':>20}|")                  # '               right|'
```

### Expressions inside f-strings

```python
values = [1, 2, 3, 4, 5]
print(f"Mean: {sum(values) / len(values):.2f}")   # Mean: 3.00

# Debugging with = (Python 3.8+)
x = 42
print(f"{x = }")         # x = 42
print(f"{x * 2 = }")     # x * 2 = 84
```

### .format() method

Older but still common in codebases and in situations where the template is defined separately from the data.

```python
template = "Epoch {epoch}: loss={loss:.4f}, acc={acc:.2%}"
print(template.format(epoch=10, loss=0.0234, acc=0.945))
# Epoch 10: loss=0.0234, acc=94.50%

# Positional
print("{0} vs {1}: {0} wins".format("model_a", "model_b"))
# model_a vs model_b: model_a wins
```

## Section 3: Indexing and Slicing

Strings support the same slicing syntax as lists: `s[start:stop:step]`.

```python
s = "ABCDEFGHIJ"
#    0123456789

print(s[0])        # A
print(s[3])        # D
print(s[-1])       # J
print(s[-3])       # H

# Slicing: s[start:stop] -- start is included, stop is excluded
print(s[2:5])      # CDE
print(s[:4])       # ABCD (from beginning)
print(s[6:])       # GHIJ (to end)
print(s[-3:])      # HIJ

# With step
print(s[::2])      # ACEGI (every other character)
print(s[::-1])     # JIHGFEDCBA (reversed)
```

### Slicing never raises IndexError

```python
s = "hello"
print(s[0:100])    # hello (no error, just goes to the end)
print(s[100:200])  # '' (empty string, no error)
```

## Section 4: Essential String Methods

### Searching

```python
text = "The quick brown fox jumps over the lazy dog"

print(text.find("fox"))          # 16 (index of first occurrence)
print(text.find("cat"))          # -1 (not found)
print(text.index("fox"))         # 16 (same, but raises ValueError if not found)
print(text.count("the"))         # 1 (case-sensitive)
print(text.startswith("The"))    # True
print(text.endswith("dog"))      # True
print("fox" in text)             # True (membership test)
```

### Transforming

```python
text = "  Hello, World!  "

print(text.strip())              # "Hello, World!" (remove whitespace from both ends)
print(text.lstrip())             # "Hello, World!  "
print(text.rstrip())             # "  Hello, World!"
print(text.strip().lower())      # "hello, world!"
print(text.strip().upper())      # "HELLO, WORLD!"
print(text.strip().title())      # "Hello, World!"
print(text.strip().swapcase())   # "hELLO, wORLD!"
```

### Replacing

```python
text = "I love cats. Cats are great. CATS!"

print(text.replace("cats", "dogs"))           # Only replaces exact case match
# "I love dogs. Cats are great. CATS!"

print(text.lower().replace("cats", "dogs"))   # Case-insensitive approach
# "i love dogs. dogs are great. dogs!"
```

### Splitting and joining

These two methods are workhorses for text processing.

```python
# split() -- string to list
sentence = "the quick brown fox"
words = sentence.split()           # ['the', 'quick', 'brown', 'fox']
print(words)

csv_line = "alice,30,engineer"
fields = csv_line.split(",")       # ['alice', '30', 'engineer']
print(fields)

# Split with maxsplit
log = "ERROR: 2024-01-15: Connection failed: timeout"
parts = log.split(": ", maxsplit=2)
print(parts)   # ['ERROR', '2024-01-15', 'Connection failed: timeout']

# join() -- list to string
words = ["hello", "world"]
print(" ".join(words))             # "hello world"
print(", ".join(words))            # "hello, world"
print("\t".join(words))            # "hello\tworld"

# Common pattern: clean and rejoin
raw = "  too   many   spaces  "
clean = " ".join(raw.split())      # "too many spaces"
print(clean)
```

### Checking content

```python
print("12345".isdigit())       # True
print("hello".isalpha())       # True
print("hello123".isalnum())    # True
print("   ".isspace())         # True
print("Hello".istitle())       # True
```

## Section 5: Raw Strings and Encoding

### Raw strings

Prefix with `r` to disable escape character processing. Essential for regex and file paths.

```python
# Without raw string
print("C:\new_folder\test")     # \n becomes a newline, \t becomes a tab

# With raw string
print(r"C:\new_folder\test")    # C:\new_folder\test (literal backslashes)
```

### Encoding

Python 3 strings are Unicode by default. When reading/writing files or network data, you deal with bytes.

```python
text = "Hello, World!"

# Encode: str -> bytes
encoded = text.encode("utf-8")
print(encoded)          # b'Hello, World!'
print(type(encoded))    # <class 'bytes'>

# Decode: bytes -> str
decoded = encoded.decode("utf-8")
print(decoded)          # Hello, World!

# Handling non-ASCII
emoji_text = "Python is fun! \U0001F40D"
encoded = emoji_text.encode("utf-8")
print(encoded)          # b'Python is fun! \xf0\x9f\x90\x8d'
print(len(emoji_text))  # 17 (characters)
print(len(encoded))     # 20 (bytes -- the snake emoji is 4 bytes in UTF-8)
```

**For AI work:** Always specify encoding explicitly when reading files. `open("file.txt", encoding="utf-8")` prevents platform-dependent surprises.

## Section 6: Brief Regex Introduction

The `re` module provides regular expression support. Regex is a mini-language for pattern matching in text.

### re.search -- find first match

```python
import re

text = "Model accuracy: 0.9543 on test set"

match = re.search(r"\d+\.\d+", text)
if match:
    print(f"Found number: {match.group()}")    # 0.9543
    print(f"Position: {match.start()}-{match.end()}")  # 17-23
```

### re.findall -- find all matches

```python
text = "epochs=100, lr=0.001, batch=32, dropout=0.3"

# Find all numbers (int and float)
numbers = re.findall(r"\d+\.?\d*", text)
print(numbers)   # ['100', '0.001', '32', '0.3']

# Find all key=value pairs
pairs = re.findall(r"(\w+)=([\d.]+)", text)
print(pairs)     # [('epochs', '100'), ('lr', '0.001'), ('batch', '32'), ('dropout', '0.3')]

config = {key: float(val) for key, val in pairs}
print(config)    # {'epochs': 100.0, 'lr': 0.001, 'batch': 32.0, 'dropout': 0.3}
```

### Common regex patterns for AI/ML work

```python
import re

# Extract email addresses
text = "Contact alice@example.com or bob@ml-lab.org"
emails = re.findall(r"[\w.-]+@[\w.-]+\.\w+", text)
print(emails)    # ['alice@example.com', 'bob@ml-lab.org']

# Clean text: remove special characters, keep alphanumeric and spaces
messy = "Hello!!! World??? #AI @ML $$$"
clean = re.sub(r"[^a-zA-Z0-9\s]", "", messy)
print(clean)     # "Hello World AI ML "

# Tokenize (simple word splitting)
text = "It's a well-known fact: NLP is hard!"
tokens = re.findall(r"\b\w+\b", text)
print(tokens)    # ['It', 's', 'a', 'well', 'known', 'fact', 'NLP', 'is', 'hard']
```

Regex is deep -- this is just enough to get started. You will learn more as specific needs arise.

## Section 7: Worked Example -- Log File Parser

Parse training logs to extract metrics.

```python
import re

log_lines = [
    "2024-01-15 10:30:01 [INFO] Epoch 1/100 - loss: 2.3456 - accuracy: 0.4521",
    "2024-01-15 10:31:15 [INFO] Epoch 2/100 - loss: 1.8732 - accuracy: 0.5893",
    "2024-01-15 10:32:28 [INFO] Epoch 3/100 - loss: 1.2145 - accuracy: 0.6754",
    "2024-01-15 10:33:41 [WARNING] GPU memory usage: 85%",
    "2024-01-15 10:34:55 [INFO] Epoch 4/100 - loss: 0.8921 - accuracy: 0.7891",
    "2024-01-15 10:36:08 [INFO] Epoch 5/100 - loss: 0.5432 - accuracy: 0.8567",
]

pattern = r"Epoch (\d+)/(\d+) - loss: ([\d.]+) - accuracy: ([\d.]+)"

results = []
for line in log_lines:
    match = re.search(pattern, line)
    if match:
        epoch = int(match.group(1))
        total = int(match.group(2))
        loss = float(match.group(3))
        acc = float(match.group(4))
        results.append({"epoch": epoch, "loss": loss, "accuracy": acc})

# Print summary
print(f"{'Epoch':>5} {'Loss':>8} {'Accuracy':>10}")
print("-" * 25)
for r in results:
    print(f"{r['epoch']:>5} {r['loss']:>8.4f} {r['accuracy']:>10.4f}")

# Compute improvement
if len(results) >= 2:
    first, last = results[0], results[-1]
    loss_drop = first["loss"] - last["loss"]
    acc_gain = last["accuracy"] - first["accuracy"]
    print(f"\nLoss decreased by {loss_drop:.4f}")
    print(f"Accuracy improved by {acc_gain:.4f}")
```

## Common Mistakes

- **Forgetting strings are immutable.** `s.upper()` does not change `s`. You must reassign: `s = s.upper()`.
- **Using `+` for concatenation in loops.** String concatenation in a loop creates a new string each time (O(n^2)). Use `"".join(list_of_strings)` instead.
  ```python
  # Slow
  result = ""
  for word in words:
      result += word + " "
  
  # Fast
  result = " ".join(words)
  ```
- **Not specifying encoding when opening files.** Always use `encoding="utf-8"` in `open()` calls.
- **Confusing `find()` and `index()`.** `find()` returns -1 on failure. `index()` raises `ValueError`. Choose based on whether "not found" is an error or an expected case.
- **Overly complex regex.** If you can solve it with `split()`, `strip()`, and `replace()`, do that instead. Regex is a power tool -- use it when simpler methods fall short.

## Solutions

### Solution 1: Text normalizer

```python
import re

def normalize_text(text):
    text = text.lower()
    text = text.strip()
    text = re.sub(r"[^a-z0-9\s]", "", text)
    text = " ".join(text.split())
    return text

# Test
raw = "  Hello,  WORLD!!!  How's it   going?  123  "
print(normalize_text(raw))
# "hello world hows it going 123"
```

**Why it works step by step:**
- `.lower()` makes everything lowercase so "WORLD" and "world" are treated the same.
- `.strip()` removes the leading and trailing spaces first so the regex and split don't have to deal with them.
- `re.sub(r"[^a-z0-9\s]", "", text)` is a regex that says "delete any character that is NOT a lowercase letter, digit, or whitespace." The `^` inside `[]` means "not these."
- `" ".join(text.split())` is the idiomatic Python way to collapse multiple spaces. `split()` with no argument splits on any whitespace run, giving a clean list of words, and `join` puts them back with single spaces.

### Solution 2: CSV parser

```python
def parse_csv(text):
    lines = text.strip().splitlines()
    headers = [h.strip() for h in lines[0].split(",")]
    result = []
    for line in lines[1:]:
        if not line.strip():
            continue
        values = [v.strip() for v in line.split(",")]
        row = dict(zip(headers, values))
        result.append(row)
    return result

# Test
csv_data = """name, age, score
Alice, 30, 95.5
Bob, 25, 87.3
Charlie, 35, 91.8"""

rows = parse_csv(csv_data)
for row in rows:
    print(row)
# {'name': 'Alice', 'age': '30', 'score': '95.5'}
# {'name': 'Bob', 'age': '25', 'score': '87.3'}
# {'name': 'Charlie', 'age': '35', 'score': '91.8'}
```

**Why it works step by step:**
- `.strip().splitlines()` removes any outer blank lines and splits the whole string into a list of individual lines.
- The header line is `lines[0]`. We split it on commas and strip each field name.
- `lines[1:]` is a slice that skips the header and gives us all the data rows.
- `zip(headers, values)` pairs each header with its corresponding value, then `dict()` turns those pairs into a dictionary. This is a very common Python pattern.
- Values stay as strings here. If you needed `age` as an integer you would cast it: `int(row["age"])`.

### Solution 3: Config file parser

```python
def parse_config(text):
    config = {}
    for line in text.splitlines():
        line = line.strip()
        if not line or line.startswith("#"):
            continue
        key, _, value = line.partition("=")
        key = key.strip()
        value = value.strip()
        # Auto-convert type
        if value.lower() == "true":
            config[key] = True
        elif value.lower() == "false":
            config[key] = False
        else:
            try:
                config[key] = int(value)
            except ValueError:
                try:
                    config[key] = float(value)
                except ValueError:
                    config[key] = value
    return config

# Test
config_text = """
# Model Configuration
model_name = gpt-small
learning_rate = 0.001
epochs = 100
dropout = 0.3
use_gpu = true
# End of config
"""

config = parse_config(config_text)
print(config)
# {'model_name': 'gpt-small', 'learning_rate': 0.001, 'epochs': 100, 'dropout': 0.3, 'use_gpu': True}
print(type(config["epochs"]))        # <class 'int'>
print(type(config["learning_rate"])) # <class 'float'>
print(type(config["use_gpu"]))       # <class 'bool'>
```

**Why it works step by step:**
- `not line` is True for empty strings, so it skips blank lines cleanly.
- `line.startswith("#")` skips comment lines.
- `.partition("=")` splits on the *first* `=` only and returns three parts: left, the separator, right. This is safer than `.split("=")` because if a value ever contained `=`, split would break it into too many pieces. The `_` variable is a Python convention meaning "I'm ignoring this value."
- The type conversion tries `bool` first (before `int`/`float`) because `int("true")` would raise an error anyway, but we want explicit bool handling. Then it tries `int`, then `float`, and falls back to `str`. Nesting `try/except` like this is called a "type coercion ladder."

### Solution 4: Regex metric extractor

```python
import re

def extract_metrics(log_lines):
    metrics = {}
    # Match patterns like "loss: 0.9543" or "accuracy: 0.8567"
    pattern = r"(\w+): ([\d.]+)"
    for line in log_lines:
        matches = re.findall(pattern, line)
        for name, value in matches:
            # Skip things that look like times (e.g. "10:30:01")
            try:
                numeric = float(value)
            except ValueError:
                continue
            if name not in metrics:
                metrics[name] = []
            metrics[name].append(numeric)
    return metrics

# Test with the log lines from the worked example
log_lines = [
    "2024-01-15 10:30:01 [INFO] Epoch 1/100 - loss: 2.3456 - accuracy: 0.4521",
    "2024-01-15 10:31:15 [INFO] Epoch 2/100 - loss: 1.8732 - accuracy: 0.5893",
    "2024-01-15 10:32:28 [INFO] Epoch 3/100 - loss: 1.2145 - accuracy: 0.6754",
    "2024-01-15 10:33:41 [WARNING] GPU memory usage: 85%",
    "2024-01-15 10:34:55 [INFO] Epoch 4/100 - loss: 0.8921 - accuracy: 0.7891",
    "2024-01-15 10:36:08 [INFO] Epoch 5/100 - loss: 0.5432 - accuracy: 0.8567",
]

results = extract_metrics(log_lines)
for metric, values in results.items():
    print(f"{metric}: {values}")
# loss: [2.3456, 1.8732, 1.2145, 0.8921, 0.5432]
# accuracy: [0.4521, 0.5893, 0.6754, 0.7891, 0.8567]
# usage: [85.0]

# Bonus: compute stats per metric
for metric, values in results.items():
    print(f"{metric}: min={min(values):.4f}, max={max(values):.4f}, last={values[-1]:.4f}")
```

**Why it works step by step:**
- The pattern `r"(\w+): ([\d.]+)"` has two capture groups (the parentheses). Group 1 matches the metric name (word characters), and group 2 matches a number that may contain a decimal point.
- `re.findall` with groups returns a list of tuples -- one tuple per match, each tuple being `(group1, group2)`. That is why we unpack with `for name, value in matches`.
- The `try/except float()` guards against edge cases where the regex matches something that looks like `name: value` but the value is not actually a number.
- `if name not in metrics: metrics[name] = []` initializes the list the first time a metric is seen. A more Pythonic alternative is `metrics.setdefault(name, []).append(numeric)`, which you will see in real codebases.
