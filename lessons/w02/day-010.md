## Section 1: Creating and Accessing Dictionaries

A dictionary maps unique, hashable keys to values. Insertion order is preserved (guaranteed since Python 3.7).

```python
# Literal syntax
model = {"name": "bert-base", "params": 110_000_000, "layers": 12}

# dict() constructor
model = dict(name="bert-base", params=110_000_000, layers=12)

# From a list of pairs
pairs = [("precision", 0.91), ("recall", 0.87), ("f1", 0.89)]
metrics = dict(pairs)
```

### Accessing Values

```python
print(model["name"])        # bert-base
# print(model["missing"])   # KeyError!

# Safe access with .get()
print(model.get("name"))           # bert-base
print(model.get("missing"))        # None
print(model.get("missing", "N/A")) # N/A  (custom default)
```

### Setting and Deleting

```python
model["epochs"] = 10         # add or update
model["layers"] = 24         # overwrite existing

del model["epochs"]          # remove key (KeyError if missing)
removed = model.pop("layers", None)  # remove and return, with default
```

## Section 2: Essential Dict Methods

```python
config = {"lr": 0.001, "batch_size": 32, "optimizer": "adam"}

# keys(), values(), items() -- return view objects
print(list(config.keys()))    # ['lr', 'batch_size', 'optimizer']
print(list(config.values()))  # [0.001, 32, 'adam']
print(list(config.items()))   # [('lr', 0.001), ('batch_size', 32), ('optimizer', 'adam')]

# Iterate over items (most common pattern)
for key, value in config.items():
    print(f"{key} = {value}")

# update() -- merge another dict into this one
overrides = {"lr": 0.0001, "dropout": 0.3}
config.update(overrides)
print(config)
# {'lr': 0.0001, 'batch_size': 32, 'optimizer': 'adam', 'dropout': 0.3}

# setdefault() -- set only if key is missing
config.setdefault("optimizer", "sgd")   # no change, key already exists
config.setdefault("weight_decay", 1e-5) # added
```

### Membership Testing

```python
if "lr" in config:
    print("Learning rate is set")
```

## Section 3: Dict Comprehensions

Same idea as list comprehensions, but produce key-value pairs.

```python
# Syntax: {key_expr: value_expr for item in iterable if condition}

# Square mapping
squares = {x: x ** 2 for x in range(1, 6)}
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Invert a dict (swap keys and values)
vocab = {"hello": 0, "world": 1, "python": 2}
index_to_word = {idx: word for word, idx in vocab.items()}
# {0: 'hello', 1: 'world', 2: 'python'}

# Filter a dict
scores = {"alice": 92, "bob": 67, "charlie": 85, "diana": 73}
passing = {name: score for name, score in scores.items() if score >= 75}
# {'alice': 92, 'charlie': 85}
```

## Section 4: defaultdict and Counter

### collections.defaultdict

A `defaultdict` automatically creates a default value when you access a missing key, eliminating the common "check-then-create" boilerplate.

```python
from collections import defaultdict

# Group words by their first letter
words = ["apple", "avocado", "banana", "blueberry", "cherry", "apricot"]
groups = defaultdict(list)
for word in words:
    groups[word[0]].append(word)

print(dict(groups))
# {'a': ['apple', 'avocado', 'apricot'], 'b': ['banana', 'blueberry'], 'c': ['cherry']}
```

Common factory functions: `list` (empty list), `int` (zero), `set` (empty set), `float` (0.0).

```python
# Count occurrences manually
counts = defaultdict(int)
for word in ["the", "cat", "sat", "on", "the", "mat"]:
    counts[word] += 1
print(dict(counts))  # {'the': 2, 'cat': 1, 'sat': 1, 'on': 1, 'mat': 1}
```

### collections.Counter

`Counter` is a specialised dict for counting hashable objects. It provides the same pattern as above in one line, plus handy extras.

```python
from collections import Counter

tokens = ["the", "cat", "sat", "on", "the", "mat", "the", "cat"]
freq = Counter(tokens)
print(freq)                    # Counter({'the': 3, 'cat': 2, 'sat': 1, 'on': 1, 'mat': 1})
print(freq.most_common(2))     # [('the', 3), ('cat', 2)]

# Arithmetic on Counters
more_tokens = Counter(["the", "dog"])
combined = freq + more_tokens
print(combined["the"])  # 4
```

## Section 5: Nested Dicts and Merging

### Nested Dicts

Real-world configs are almost always nested.

```python
experiment = {
    "model": {
        "name": "resnet50",
        "layers": 50,
        "pretrained": True,
    },
    "training": {
        "lr": 0.001,
        "epochs": 100,
        "batch_size": 32,
    },
    "data": {
        "dataset": "imagenet",
        "augmentation": ["flip", "rotate", "crop"],
    },
}

# Access nested values
lr = experiment["training"]["lr"]
augments = experiment["data"]["augmentation"]
```

### Merging Dicts (Python 3.9+)

```python
defaults = {"lr": 0.001, "batch_size": 32, "optimizer": "sgd"}
overrides = {"lr": 0.0003, "dropout": 0.2}

# The | operator creates a new merged dict; right side wins on conflicts
merged = defaults | overrides
print(merged)
# {'lr': 0.0003, 'batch_size': 32, 'optimizer': 'sgd', 'dropout': 0.2}

# In-place merge with |=
defaults |= overrides
```

For Python 3.5-3.8, use `{**defaults, **overrides}` instead.

## Section 6: Worked Example -- Building a Vocabulary Index

A common NLP preprocessing step is mapping tokens to integer IDs.

```python
from collections import Counter

corpus = [
    "the cat sat on the mat",
    "the dog sat on the log",
    "the cat chased the dog",
]

# Tokenise and count
all_tokens = []
for sentence in corpus:
    all_tokens.extend(sentence.split())

freq = Counter(all_tokens)
print(freq.most_common(5))
# [('the', 6), ('cat', 2), ('sat', 2), ('dog', 2), ('on', 2)]

# Build vocab: most frequent tokens get lowest IDs
# Reserve 0 for <PAD> and 1 for <UNK>
vocab = {"<PAD>": 0, "<UNK>": 1}
for idx, (token, _count) in enumerate(freq.most_common(), start=2):
    vocab[token] = idx

print(vocab)
# {'<PAD>': 0, '<UNK>': 1, 'the': 2, 'cat': 3, 'sat': 4, ...}

# Encode a sentence
sentence = "the bird sat on the fence"
encoded = [vocab.get(tok, vocab["<UNK>"]) for tok in sentence.split()]
print(encoded)
# [2, 1, 4, 5, 2, 1]  -- 'bird' and 'fence' map to <UNK>=1
```

## Common Mistakes

- **Using `d[key]` on a key that might be missing:** Always use `d.get(key, default)` or check `if key in d` first, unless you want the `KeyError` to signal a bug.
- **Mutating a dict while iterating over it:** This raises `RuntimeError`. Iterate over a copy of the keys: `for k in list(d.keys()):`.
- **Using a mutable object as a dict key:** Lists and dicts are not hashable. Use tuples or frozensets as keys instead.
- **Forgetting that `update()` mutates in place:** It does not return a new dict. If you need a new dict, use `{**a, **b}` or `a | b`.
