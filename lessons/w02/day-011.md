## Section 1: Creating Sets

A set is an **unordered** collection of **unique**, **hashable** elements.

```python
# From a literal (curly braces, but NOT empty -- {} is an empty dict)
fruits = {"apple", "banana", "cherry"}
print(type(fruits))  # <class 'set'>

# Empty set must use the constructor
empty = set()

# From an iterable -- duplicates are removed automatically
nums = set([1, 2, 2, 3, 3, 3])
print(nums)  # {1, 2, 3}

# From a string -- each character becomes an element
chars = set("mississippi")
print(chars)  # {'m', 'i', 's', 'p'}
```

### Adding and Removing Elements

```python
tags = {"nlp", "transformer"}

tags.add("bert")            # add one element
tags.update(["gpt", "t5"]) # add multiple elements from an iterable

tags.remove("gpt")          # remove -- raises KeyError if missing
tags.discard("nonexistent") # discard -- silent if missing

popped = tags.pop()         # remove and return an arbitrary element
tags.clear()                # remove all elements
```

## Section 2: Set Operations

Sets support the standard mathematical operations. Each has both an operator form and a method form.

```python
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}
```

### Union (all elements from both)

```python
print(a | b)            # {1, 2, 3, 4, 5, 6, 7, 8}
print(a.union(b))       # same
```

### Intersection (elements in both)

```python
print(a & b)                # {4, 5}
print(a.intersection(b))   # same
```

### Difference (in a but not in b)

```python
print(a - b)              # {1, 2, 3}
print(a.difference(b))    # same
```

### Symmetric Difference (in either but not both)

```python
print(a ^ b)                        # {1, 2, 3, 6, 7, 8}
print(a.symmetric_difference(b))    # same
```

### Subset and Superset

```python
small = {1, 2}
big = {1, 2, 3, 4, 5}

print(small <= big)    # True  -- small is a subset of big
print(small.issubset(big))  # True
print(big >= small)    # True  -- big is a superset of small
```

## Section 3: Set Comprehensions

Same syntax as list comprehensions but with curly braces.

```python
# Unique word lengths in a sentence
sentence = "the quick brown fox jumps over the lazy dog"
lengths = {len(word) for word in sentence.split()}
print(lengths)  # {3, 4, 5}

# Extract unique labels from predictions
predictions = [
    {"text": "Great!", "label": "positive"},
    {"text": "Terrible", "label": "negative"},
    {"text": "Awesome", "label": "positive"},
    {"text": "Bad", "label": "negative"},
    {"text": "OK", "label": "neutral"},
]
unique_labels = {pred["label"] for pred in predictions}
print(unique_labels)  # {'positive', 'negative', 'neutral'}
```

## Section 4: Frozen Sets

A `frozenset` is an immutable version of a set. Because it is immutable and hashable, you can use it as a dict key or as an element of another set.

```python
fs = frozenset([1, 2, 3])

# fs.add(4)  # AttributeError -- frozenset is immutable

# Use as a dict key
feature_combos = {
    frozenset(["age", "income"]): 0.85,
    frozenset(["age", "income", "education"]): 0.91,
}
print(feature_combos[frozenset(["age", "income"])])  # 0.85

# Set of sets (not possible with regular sets)
power_set_elements = {frozenset(), frozenset([1]), frozenset([2]), frozenset([1, 2])}
```

### When to Use frozenset

- When you need a set as a dictionary key
- When you need to store sets inside other sets
- When you want to guarantee immutability for safety

## Section 5: Practical Uses in AI/ML

### Deduplication

```python
raw_data = [
    "the cat sat on the mat",
    "The Cat Sat On The Mat",    # duplicate after lowering
    "the dog sat on the log",
    "the cat sat on the mat",    # exact duplicate
]

unique = list({s.lower() for s in raw_data})
print(unique)
# ['the cat sat on the mat', 'the dog sat on the log']
```

### Fast Membership Testing

Checking `x in my_set` is O(1) on average, compared to O(n) for `x in my_list`.

```python
# Build a stopword set once
stopwords = {"the", "a", "an", "is", "in", "on", "at", "to", "and", "of", "for"}

tokens = "the model is trained on a large dataset for classification".split()
filtered = [tok for tok in tokens if tok not in stopwords]
print(filtered)  # ['model', 'trained', 'large', 'dataset', 'classification']
```

### Finding Common or Missing Features

```python
model_a_features = {"age", "income", "education", "zip_code"}
model_b_features = {"age", "income", "credit_score", "employment"}

common = model_a_features & model_b_features
print(f"Shared features: {common}")       # {'age', 'income'}

only_a = model_a_features - model_b_features
print(f"Only in Model A: {only_a}")       # {'education', 'zip_code'}

all_features = model_a_features | model_b_features
print(f"All features: {all_features}")
```

## Section 6: Worked Example -- Data Cleaning Pipeline

```python
from collections import Counter

# Raw training data with duplicates and near-duplicates
raw_samples = [
    "  This movie is great!  ",
    "this movie is great!",
    "Terrible film, waste of time.",
    "terrible film, waste of time.",
    "An average experience overall.",
    "  This movie is great!  ",
    "AN AVERAGE EXPERIENCE OVERALL.",
]

# Step 1: Normalise (strip whitespace, lowercase)
normalised = [s.strip().lower() for s in raw_samples]

# Step 2: Deduplicate while preserving order
seen = set()
unique = []
for sample in normalised:
    if sample not in seen:
        seen.add(sample)
        unique.append(sample)

print(f"Before: {len(raw_samples)} samples")
print(f"After:  {len(unique)} unique samples")
for s in unique:
    print(f"  - {s}")

# Step 3: Verify no duplicates remain
assert len(unique) == len(set(unique)), "Duplicates still present!"
```

Output:

```
Before: 7 samples
After:  3 unique samples
  - this movie is great!
  - terrible film, waste of time.
  - an average experience overall.
```

## Common Mistakes

- **Using `{}` for an empty set:** `{}` creates an empty dict, not a set. Always use `set()` for empty sets.
- **Expecting sets to be ordered:** Sets have no guaranteed order. If you need ordered unique elements, use `dict.fromkeys(iterable)` (Python 3.7+) which preserves insertion order.
- **Adding unhashable elements:** Lists and dicts cannot be added to sets. Use tuples or frozensets instead.
- **Forgetting that set operations return new sets:** `a.union(b)` does not modify `a`. Use `a |= b` or `a.update(b)` for in-place modification.
